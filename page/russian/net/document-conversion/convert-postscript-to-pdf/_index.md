## Импорт пространств имён

Директивы `using` дают доступ к основным классам конвертации. Поместите следующие строки в начало вашего C# файла:

```csharp
using Aspose.Page.EPS;
using Aspose.Page.EPS.Device;
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
```

## Шаг 1: Инициализация потоков

Начните с инициализации входных и выходных потоков для файлов PostScript и PDF. Замените `"Your Document Directory"` на реальный путь к папке, содержащей ваши файлы `.ps`.

```csharp
// The path to the documents directory.
string dataDir = "Your Document Directory";
// Initialize PDF output stream
System.IO.FileStream pdfStream = new System.IO.FileStream(dataDir + "outputPDF_out.pdf", System.IO.FileMode.Create, System.IO.FileAccess.Write);
// Initialize PostScript input stream
System.IO.FileStream psStream = new System.IO.FileStream(dataDir + "input.ps", System.IO.FileMode.Open, System.IO.FileAccess.Read);
PsDocument document = new PsDocument(psStream);
```

## Шаг 2: Установка параметров конвертации

Чтобы управлять процессом конвертации, создайте объект `Options` и настройте необходимые параметры. В этом примере мы включаем подавление ошибок, чтобы конвертация продолжалась, даже если источник содержит некритические проблемы.

Класс `Options` инкапсулирует настройки конвертации, такие как обработка ошибок и конфигурация папок шрифтов.

```csharp
// If you want to convert Postscript file despite of minor errors set this flag
bool suppressErrors = true;
// Initialize options object with necessary parameters.
PdfSaveOptions options = new PdfSaveOptions(suppressErrors);
// If you want to add a special folder where fonts are stored. Default fonts folder in OS is always included.
options.AdditionalFontsFolders = new string[] { @"{FONT_FOLDER}" };
```

> **Совет:** Используйте свойство `AdditionalFontsFolders`, когда вам нужно **add custom fonts pdf** файлы, которые не установлены в ОС.

## Шаг 3: Инициализация PDF‑устройства

Создайте PDF‑устройство, которое будет принимать отрисованные страницы. При желании можно указать размер страницы, разрешение изображения и другие подсказки рендеринга.

Класс `PdfDevice` получает отрисованные страницы и записывает их в PDF‑поток.

```csharp
// Default page size is 595x842 and it is not mandatory to set it in PdfDevice
Aspose.Page.EPS.Device.PdfDevice device = new Aspose.Page.EPS.Device.PdfDevice(pdfStream);
// But if you need to specify size and image format use the following line
//Aspose.Page.EPS.Device.PdfDevice device = new Aspose.Page.EPS.Device.PdfDevice(pdfStream, new System.Drawing.Size(595, 842));
```

## Шаг 4: Сохранение документа

Вызовите метод `Save` у устройства, передав выходной поток и параметры, настроенные ранее.

Метод `Save` устройства записывает отрисованное содержимое в выходной поток, используя указанные параметры.

```csharp
try
{
    document.Save(device, options);
}
finally
{
    psStream.Close();
    pdfStream.Close();
}
```

## Шаг 5: Обзор ошибок

После конвертации пройдитесь по всем захваченным исключениям, чтобы понять, какие незначительные проблемы были подавлены. Этот шаг важен для крупномасштабных пакетных задач, где требуется пост‑операционный аудит.

Коллекция `Exceptions` содержит все некритические ошибки, зафиксированные во время конвертации.

```csharp
// Review errors
if (suppressErrors)
{
    foreach (Exception ex in options.Exceptions)
    {
        Console.WriteLine(ex.Message);
    }
}
```

### Распространённые подводные камни и как их избежать

| Проблема | Почему происходит | Решение |
|----------|-------------------|---------|
| Шрифты не отображаются | Пользовательские шрифты не находятся в системной папке шрифтов | Добавьте путь к папке в `options.AdditionalFontsFolders` |
| Отсутствуют страницы | Входной PostScript содержит ошибки | Установите `suppressErrors = true`, чтобы продолжить конвертацию и просмотреть `options.Exceptions` |
| Файл вывода заблокирован | Поток не закрыт корректно | Всегда закрывайте оба потока `psStream` и `pdfStream` в блоке `finally` (как показано) |
