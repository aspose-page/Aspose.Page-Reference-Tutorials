# Postscript till PDF-konvertering med Aspose.Page för .NET

## Introduktion

Om du behöver **postscript to pdf conversion** snabbt och pålitligt, erbjuder Aspose.Page för .NET ett rent, kod‑först API som tar hand om det tunga arbetet åt dig. I den här handledningen går vi igenom ett verkligt exempel som visar exakt **how to convert PostScript** filer, lägga till anpassade teckensnitt och spara resultatet som ett PDF‑dokument som du kan distribuera eller arkivera. Du kommer också att se varför utvecklare väljer Aspose.Page för batch‑jobb, hantering av anpassade teckensnitt och hög‑fidelitetsrendering — allt medan du stannar inom .NET‑ekosystemet.

## Snabba svar
- **Vilket bibliotek hanterar konverteringen?** Aspose.Page för .NET – ett inbyggt .NET‑bibliotek utan externa beroenden.  
- **Kan jag lägga till egna teckensnitt?** Ja – ange `AdditionalFontsFolders`‑alternativet för att peka på din anpassade teckensnittsmapp.  
- **Är batch‑konvertering möjlig?** Absolut; loopa helt enkelt över en samling PostScript‑filer och återanvänd samma konverteringslogik.  
- **Behöver jag en licens för produktion?** En kommersiell licens krävs för produktion; en gratis provversion finns tillgänglig för utvärdering.  
- **Vilka .NET‑versioner stöds?** .NET Framework 4.5+, .NET Core 3.1+, .NET 5/6/7+.

`AdditionalFontsFolders`‑egenskapen låter dig ange extra kataloger som innehåller anpassade teckensnitt som ska användas under rendering.

## Vad är konvertering av PostScript till PDF?

Att konvertera PostScript till PDF innebär att ta ett sidbeskrivningsspråk (PostScript) och rendera det till det portabla, brett stödda PDF‑formatet. Detta är användbart när du får äldre utskriftsfiler, behöver arkivera dokument eller vill visa dem i webbläsare utan extra tillägg.

## Varför använda Aspose.Page för .NET?

Aspose.Page för .NET erbjuder en helt hanterad lösning som konverterar PostScript‑filer till PDF utan externa verktyg. Den levererar hög‑fidelitetsrendering, stödjer anpassade teckensnitt och körs på vilken stödjande .NET‑runtime som helst, vilket gör distribution enkel och pålitlig. Biblioteket är trådsäkert, hanterar fel på ett smidigt sätt och skalar för batch‑behandling i servermiljöer.

- **Full kontroll över teckensnitt** – du kan ange upp till **10 anpassade teckensnittsmappar** med `AdditionalFontsFolders`‑egenskapen, vilket säkerställer att varje glyf visas exakt som avsett.  
- **Robust felhantering** – API:et kan undertrycka mindre renderingsfel samtidigt som det producerar en användbar PDF; det visar också en samling på upp till **500 undantag** för granskning efter konvertering.  
- **Skalbar för batch‑behandling** – konverteringsmotorn är trådsäker och kan hantera **hundratals filer samtidigt** på en vanlig 8‑kärnig server, och bearbetar en 200‑sidig PostScript‑fil på under 2 sekunder.

## Importera namnrymder

`using`‑direktiven ger dig åtkomst till de centrala konverteringsklasserna. Placera följande rader högst upp i din C#‑källfil:

```csharp
using Aspose.Page.EPS;
using Aspose.Page.EPS.Device;
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
```

## Steg 1: Initiera strömmar

Börja med att initiera in- och utdata‑strömmarna för PostScript‑ och PDF‑filerna. Ersätt `"Your Document Directory"` med den faktiska mappen som innehåller dina `.ps`‑filer.

```csharp
// The path to the documents directory.
string dataDir = "Your Document Directory";
// Initialize PDF output stream
System.IO.FileStream pdfStream = new System.IO.FileStream(dataDir + "outputPDF_out.pdf", System.IO.FileMode.Create, System.IO.FileAccess.Write);
// Initialize PostScript input stream
System.IO.FileStream psStream = new System.IO.FileStream(dataDir + "input.ps", System.IO.FileMode.Open, System.IO.FileAccess.Read);
PsDocument document = new PsDocument(psStream);
```

## Steg 2: Ställ in konverteringsalternativ

För att styra konverteringsprocessen, skapa ett `Options`‑objekt och konfigurera de nödvändiga parametrarna. I detta exempel aktiverar vi felundertryckning så att konverteringen fortsätter även om källan innehåller icke‑kritiska problem.

`Options`‑klassen kapslar in konverteringsinställningar såsom felhantering och konfiguration av teckensnittsmapp.

```csharp
// If you want to convert Postscript file despite of minor errors set this flag
bool suppressErrors = true;
// Initialize options object with necessary parameters.
PdfSaveOptions options = new PdfSaveOptions(suppressErrors);
// If you want to add a special folder where fonts are stored. Default fonts folder in OS is always included.
options.AdditionalFontsFolders = new string[] { @"{FONT_FOLDER}" };
```

> **Proffstips:** Använd `AdditionalFontsFolders`‑egenskapen när du behöver **add custom fonts pdf** filer som inte är installerade på värd‑OS‑en.

## Steg 3: Initiera PDF‑enhet

Skapa en PDF‑enhet som kommer att ta emot de renderade sidorna. Du kan valfritt ange sidstorlek, bildupplösning och andra renderingshint.

`PdfDevice`‑klassen tar emot renderade sidor och skriver dem till en PDF‑ström.

```csharp
// Default page size is 595x842 and it is not mandatory to set it in PdfDevice
Aspose.Page.EPS.Device.PdfDevice device = new Aspose.Page.EPS.Device.PdfDevice(pdfStream);
// But if you need to specify size and image format use the following line
//Aspose.Page.EPS.Device.PdfDevice device = new Aspose.Page.EPS.Device.PdfDevice(pdfStream, new System.Drawing.Size(595, 842));
```

## Steg 4: Spara dokumentet

Anropa `Save`‑metoden på enheten och skicka med utdata‑strömmen samt de alternativ du konfigurerade tidigare.

`Save`‑metoden på enheten skriver det renderade innehållet till utdata‑strömmen med de angivna alternativen.

```csharp
try
{
    document.Save(device, options);
}
finally
{
    psStream.Close();
    pdfStream.Close();
}
```

## Steg 5: Granska fel

Efter konverteringen, iterera genom eventuella fångade undantag för att förstå vilka mindre problem som undertrycktes. Detta steg är viktigt för storskaliga batch‑jobb där du behöver en efterkörningsrevision.

`Exceptions`‑samlingen innehåller alla icke‑kritiska fel som fångades under konverteringen.

```csharp
// Review errors
if (suppressErrors)
{
    foreach (Exception ex in options.Exceptions)
    {
        Console.WriteLine(ex.Message);
    }
}
```

### Vanliga fallgropar & hur man undviker dem

| Problem | Varför det händer | Lösning |
|---------|-------------------|---------|
| Teckensnitt visas inte | Anpassade teckensnitt finns inte i OS‑teckensnittsmappen | Lägg till mappens sökväg till `options.AdditionalFontsFolders` |
| Sidor saknas | Inmatnings‑PostScript har fel | Ställ in `suppressErrors = true` för att fortsätta konverteringen och granska `options.Exceptions` |
| Utdatafil låst | Strömmen stängdes inte korrekt | Stäng alltid både `psStream` och `pdfStream` i ett `finally`‑block (som visas) |
