## 如何使用 Aspose Page 在 XPS 中加入漸層

載入 XPS 文件、建立漸層筆刷，並套用至形狀或頁面背景——整個工作流程只需不到 10 行 Java 程式碼。Aspose.Page 會自動處理顏色插值、角度計算與 XML 序列化，讓您即時取得可直接列印的 XPS 檔案。

### 對角線漸層：提升視覺卓越

`LinearGradientBrush` 類別代表可套用於形狀的線性漸層填充。想像一下：一個具有動態對角線漸層的 Java XPS 文件，無縫混合顏色以打造美學傑作。我們的專屬教學會一步步指導您，從以 45° 角度初始化 `LinearGradientBrush` 到將其套用於矩形形狀。

### 水平漸層：無縫整合揭示
#### [在 Java XPS 中加入水平漸層](./horizontal/)

`LinearGradientBrush` 類別定義可套用於 `Path` 的線性漸層。水平漸層提供平滑的左至右顏色過渡，適合用於標題、頁腳或背景條。連結的指南說明如何設定漸層的起始與結束點、選擇任意數量的顏色停點，並將筆刷附加至 `Path` 物件。

### 垂直漸層：輕鬆提升視覺吸引力
#### [在 Java XPS 中加入垂直漸層](./vertical/)

`LinearGradientBrush` 類別代表可套用於形狀的線性漸層填充。垂直漸層透過自上而下的顏色漸變，增添精緻感。我們的逐步教學示範如何以 90° 方向建立 `LinearGradientBrush`、將其套用於跨頁的矩形，並在多頁間重複使用筆刷以保持檔案大小最小化。

**Q: 我可以在商業專案中使用這些漸層技術嗎？**

**Q: 能在單一 XPS 頁面中結合多種漸層類型嗎？**
