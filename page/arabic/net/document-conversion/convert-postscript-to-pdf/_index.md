# تحويل Postscript إلى PDF باستخدام Aspose.Page لـ .NET

## المقدمة

إذا كنت بحاجة إلى **تحويل postscript إلى pdf** بسرعة وموثوقية، فإن Aspose.Page لـ .NET يقدم واجهة برمجة تطبيقات نظيفة تعتمد على الكود أولاً وتقوم بالعمل الشاق نيابةً عنك. في هذا البرنامج التعليمي سنستعرض مثالًا واقعيًا يوضح بالضبط **كيفية تحويل ملفات PostScript**، وإضافة خطوط مخصصة، وحفظ النتيجة كمستند PDF يمكنك توزيعه أو أرشفته. سترى أيضًا لماذا يختار المطورون Aspose.Page للوظائف الدفعية، ومعالجة الخطوط المخصصة، وعرض عالي الدقة — كل ذلك داخل بيئة .NET.

## إجابات سريعة
- **ما المكتبة التي تتعامل مع التحويل؟** Aspose.Page لـ .NET – مكتبة .NET أصلية بدون تبعيات خارجية.  
- **هل يمكنني إضافة خطوط خاصة بي؟** نعم – اضبط خيار `AdditionalFontsFolders` للإشارة إلى دليل الخطوط المخصص الخاص بك.  
- **هل التحويل الدفعي ممكن؟** بالتأكيد؛ فقط قم بالتكرار عبر مجموعة من ملفات PostScript وأعد استخدام نفس منطق التحويل.  
- **هل أحتاج إلى ترخيص للإنتاج؟** الترخيص التجاري مطلوب للإنتاج؛ نسخة تجريبية مجانية متاحة للتقييم.  
- **ما إصدارات .NET المدعومة؟** .NET Framework 4.5+، .NET Core 3.1+، .NET 5/6/7+.

خاصية `AdditionalFontsFolders` تتيح لك تحديد أدلة إضافية تحتوي على خطوط مخصصة لاستخدامها أثناء العرض.

## ما هو تحويل PostScript إلى PDF؟

تحويل PostScript إلى PDF يعني أخذ لغة وصف الصفحات (PostScript) وعرضها في تنسيق PDF المحمول والمدعوم على نطاق واسع. هذا مفيد عندما تتلقى ملفات طباعة قديمة، أو تحتاج إلى أرشفة المستندات، أو تريد عرضها في المتصفحات دون إضافات إضافية.

## لماذا تستخدم Aspose.Page لـ .NET؟

Aspose.Page لـ .NET يوفر حلاً مُدارًا بالكامل يحول ملفات PostScript إلى PDF دون أدوات خارجية. يقدم عرضًا عالي الدقة، يدعم الخطوط المخصصة، ويعمل على أي بيئة تشغيل .NET مدعومة، مما يجعل النشر بسيطًا وموثوقًا. المكتبة آمنة للعمليات المتعددة (thread‑safe)، تتعامل مع الأخطاء بلطف، وتتكيف مع المعالجة الدفعية في بيئات الخوادم.

- **عدم وجود تبعيات خارجية** – تُوزَّع المكتبة كحزمة NuGet واحدة، مما يقلل تعقيد النشر.  
- **تحكم كامل في الخطوط** – يمكنك توفير ما يصل إلى **10 مجلدات خطوط مخصصة** باستخدام خاصية `AdditionalFontsFolders`، لضمان ظهور كل حرف كما هو مقصود.  
- **معالجة أخطاء قوية** – يمكن لواجهة البرمجة (API) قمع الأخطاء الطفيفة في العرض مع الاستمرار في إنتاج PDF قابل للاستخدام؛ كما تُظهر مجموعة تصل إلى **500 استثناء** لمراجعة ما بعد التحويل.  
- **قابلة للتوسع للمعالجة الدفعية** – محرك التحويل آمن للعمليات المتعددة ويمكنه معالجة **مئات الملفات في وقت واحد** على خادم عادي بثمانية أنوية، حيث يعالج ملف PostScript مكوّن من 200 صفحة في أقل من 2 ثانية.

## استيراد مساحات الأسماء

توفر توجيهات `using` الوصول إلى الفئات الأساسية للتحويل. ضع الأسطر التالية في أعلى ملف C# الخاص بك:

```csharp
using Aspose.Page.EPS;
using Aspose.Page.EPS.Device;
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
```

## الخطوة 1: تهيئة التدفقات

ابدأ بتهيئة تدفقات الإدخال والإخراج لملفات PostScript وPDF. استبدل `"Your Document Directory"` بالمجلد الفعلي الذي يحتوي على ملفات `.ps` الخاصة بك.

```csharp
// The path to the documents directory.
string dataDir = "Your Document Directory";
// Initialize PDF output stream
System.IO.FileStream pdfStream = new System.IO.FileStream(dataDir + "outputPDF_out.pdf", System.IO.FileMode.Create, System.IO.FileAccess.Write);
// Initialize PostScript input stream
System.IO.FileStream psStream = new System.IO.FileStream(dataDir + "input.ps", System.IO.FileMode.Open, System.IO.FileAccess.Read);
PsDocument document = new PsDocument(psStream);
```

## الخطوة 2: ضبط خيارات التحويل

للتحكم في عملية التحويل، أنشئ كائن `Options` وقم بتهيئة المعلمات اللازمة. في هذا المثال نُفعّل قمع الأخطاء بحيث يستمر التحويل حتى إذا كان المصدر يحتوي على مشكلات غير حرجة.

فئة `Options` تُجسد إعدادات التحويل مثل معالجة الأخطاء وتكوين مجلد الخطوط.

```csharp
// If you want to convert Postscript file despite of minor errors set this flag
bool suppressErrors = true;
// Initialize options object with necessary parameters.
PdfSaveOptions options = new PdfSaveOptions(suppressErrors);
// If you want to add a special folder where fonts are stored. Default fonts folder in OS is always included.
options.AdditionalFontsFolders = new string[] { @"{FONT_FOLDER}" };
```

> **نصيحة احترافية:** استخدم خاصية `AdditionalFontsFolders` كلما احتجت إلى **إضافة خطوط pdf مخصصة** التي لم تُثبت على نظام التشغيل المضيف.

## الخطوة 3: تهيئة جهاز PDF

أنشئ جهاز PDF سيستقبل الصفحات المُعالجة. يمكنك اختيارياً تحديد حجم الصفحة، دقة الصورة، وغيرها من تلميحات العرض.

فئة `PdfDevice` تستقبل الصفحات المُعالجة وتكتبها إلى تدفق PDF.

```csharp
// Default page size is 595x842 and it is not mandatory to set it in PdfDevice
Aspose.Page.EPS.Device.PdfDevice device = new Aspose.Page.EPS.Device.PdfDevice(pdfStream);
// But if you need to specify size and image format use the following line
//Aspose.Page.EPS.Device.PdfDevice device = new Aspose.Page.EPS.Device.PdfDevice(pdfStream, new System.Drawing.Size(595, 842));
```

## الخطوة 4: حفظ المستند

استدعِ طريقة `Save` على الجهاز، مع تمرير تدفق الإخراج والخيارات التي قمت بتهيئتها مسبقًا.

طريقة `Save` على الجهاز تكتب المحتوى المُعالج إلى تدفق الإخراج باستخدام الخيارات المحددة.

```csharp
try
{
    document.Save(device, options);
}
finally
{
    psStream.Close();
    pdfStream.Close();
}
```

## الخطوة 5: مراجعة الأخطاء

بعد التحويل، قم بالتكرار عبر أي استثناءات تم التقاطها لفهم ما هي المشكلات الطفيفة التي تم قمعها. هذه الخطوة أساسية للوظائف الدفعية على نطاق واسع حيث تحتاج إلى تدقيق ما بعد التنفيذ.

مجموعة `Exceptions` تحتوي على أي أخطاء غير حرجة تم التقاطها أثناء التحويل.

```csharp
// Review errors
if (suppressErrors)
{
    foreach (Exception ex in options.Exceptions)
    {
        Console.WriteLine(ex.Message);
    }
}
```

| المشكلة | سبب حدوثها | الحل |
|---------|------------|------|
| عدم عرض الخطوط | الخطوط المخصصة غير موجودة في مجلد خطوط نظام التشغيل | أضف مسار المجلد إلى `options.AdditionalFontsFolders` |
| الصفحات مفقودة | ملف PostScript المدخل يحتوي على أخطاء | عيّن `suppressErrors = true` لمتابعة التحويل ومراجعة `options.Exceptions` |
| قفل ملف الإخراج | عدم إغلاق التدفق بشكل صحيح | دائمًا أغلق كل من `psStream` و `pdfStream` في كتلة `finally` (كما هو موضح) |
