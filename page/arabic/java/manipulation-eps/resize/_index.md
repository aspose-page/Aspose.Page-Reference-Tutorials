# كيفية تغيير حجم ملفات EPS المتجهة في Java باستخدام Aspose.Page

## مقدمة
إذا كنت بحاجة إلى **java vector resize** ملفات EPS برمجياً، فأنت في المكان الصحيح. يوضح هذا الدرس كيفية تغيير حجم صور EPS في Java باستخدام مكتبة Aspose.Page. سواء كنت تريد مضاعفة الحجم، أو تقليصه إلى قياس محدد، أو العمل بالنسب المئوية، فإن الخطوات أدناه تمنحك التحكم الكامل في أبعاد الإخراج. إتقان طريقة تغيير حجم EPS أمر أساسي عند تعديل الرسومات لتناسب تخطيطات طباعة مختلفة، أو دقات شاشات، أو إرشادات العلامة التجارية.

## إجابات سريعة
- **ما المكتبة المطلوبة؟** Aspose.Page for Java

- **هل أحتاج إلى ترخيص للتطوير؟** نسخة تجريبية مجانية تعمل للاختبار؛ الترخيص مطلوب للإنتاج.

## ما هو EPS ولماذا يتم تغيير حجمه؟
Encapsulated PostScript (EPS) هو تنسيق رسومات متجهية يُستخدم على نطاق واسع في الطباعة والنشر. أحيانًا يتم إنشاء ملف EPS الأصلي بحجم لا يتطابق مع المخرجات المستهدفة – على سبيل المثال، قد يحتاج شعار صُنع بـ 72 نقطة إلى أن يكون 144 نقطة لكتيب أكبر. معرفة **how to resize eps** تتيح لك الحفاظ على جودة المتجه مع تعديل الأبعاد لأي سير عمل.

## لماذا نستخدم Aspose.Page لتغيير حجم EPS؟
توفر Aspose.Page واجهة برمجة تطبيقات بسيطة تسمح لك بتحديد الحجم المستهدف بأي من الوحدات المدعومة مع الحفاظ تلقائيًا على بنية المتجه. تتولى المكتبة تحويل الوحدات داخليًا، لذا يمكنك التركيز على الأبعاد المطلوبة دون حسابات يدوية.

- **يدعم أربع وحدات قياس** – Points, Inches, Millimeters, and Percent.  
- **بدون تبعيات خارجية** – API جافا نقي، لا يتطلب مكتبات أصلية.  
- **معالجة عالية الأداء** – يمكنه معالجة ما يصل إلى 500 ملف EPS في الدقيقة على خادم قياسي بثمانية نوى.  
- **يحافظ على دقة المتجه** – يظل الناتج قابلاً للتوسيع بالكامل دون تحويل إلى نقطية.

## كيفية تغيير أبعاد EPS باستخدام وحدات مختلفة
يمكنك تغيير أبعاد EPS عن طريق استدعاء طريقة `resizeEps` مع العرض والارتفاع المطلوبين وقيمة تعداد `Units`؛ يعمل ذلك للنقاط، البوصات، المليمترات أو النسب المئوية. النمط المكوّن من خمس خطوات ينطبق على كل وحدة، مما يجعل API متوقعًا وسهل التكامل.

`resizeEps` يغيّر حجم لوحة EPS إلى الأبعاد المحددة مع الحفاظ على بيانات المتجه الداخلية.

## كيفية تغيير حجم EPS باستخدام النقاط
حمّل ملف EPS الخاص بك، حدد الحجم الجديد بالنقاط، واحفظ النتيجة. يضاعف هذا النهج الأبعاد الأصلية مع الحفاظ على نسبة الأبعاد. استخدام النقاط يمنحك تحكمًا دقيقًا في الأحجام الجاهزة للطباعة، وهو مفيد بشكل خاص لتخطيطات الطباعة الطباعية وإخراج عالي الدقة.

### الخطوة 1: إعداد تدفق الإدخال
```java
FileInputStream inputEpsStream = new FileInputStream(dataDir + "input.eps");
```

### الخطوة 2: تهيئة كائن `PsDocument`
`PsDocument` يحمّل ملف EPS المصدر ويوفر طرقًا للتلاعب به.  

```java
PsDocument doc = new PsDocument(inputEpsStream);
```

### الخطوة 3: استخراج الحجم الحالي لصورة EPS
```java
Dimension oldSize = doc.extractEpsSize();
```

### الخطوة 4: إنشاء تدفق إخراج للملف المعاد حجمه
```java
FileOutputStream outputEpsStream = new FileOutputStream(dataDir + "output_resize_points.eps");
```

### الخطوة 5: تغيير الحجم وحفظ EPS باستخدام النقاط
```java
doc.resizeEps(outputEpsStream, new Dimension2D.Double(oldSize.width * 2, oldSize.height * 2), Units.Points);
```

## كيفية تغيير حجم EPS باستخدام البوصات
يتيح لك تغيير الحجم باستخدام البوصات مطابقة المواصفات المحددة بالوحدات الإمبراطورية، مثل تخطيطات الكتيبات أو معايير الطباعة في الولايات المتحدة. قدم العرض والارتفاع المستهدفين بالبوصة، وستقوم API بتحويلهما إلى الوحدات الداخلية المناسبة قبل تطبيق التحويل.

## كيفية تغيير حجم EPS باستخدام المليمترات
عند العمل في سير عمل يعتمد على النظام المتري، يضمن تحديد الأبعاد بالمليمترات التوافق مع أحجام الورق ومعدات الطباعة المستخدمة خارج الولايات المتحدة. تتولى المكتبة تلقائيًا تحويل المليمترات إلى نظام الإحداثيات الداخلي.

## كيفية تغيير حجم EPS باستخدام النسب المئوية
يؤدي تغيير الحجم بالنسبة المئوية إلى تكبير أو تصغير الأبعاد الأصلية بشكل متناسب، وهو مفيد لتعديلات سريعة دون حساب القيم المطلقة. على سبيل المثال، العامل `0.5` يقلل كل من العرض والارتفاع بنسبة 50 %.

## الأخطاء الشائعة والنصائح
- **دائمًا أغلق التدفقات** – في كود الإنتاج، غلف التدفقات باستخدام try‑with‑resources لتجنب قفل الملفات.  
- **حافظ على نسبة العرض إلى الارتفاع** – اضرب كل من العرض والارتفاع في نفس العامل ما لم تكن تريد التشويه عمدًا.  
- **تحقق من DPI** – تغيير الحجم لا يغير DPI؛ إذا كنت بحاجة إلى DPI مختلف، قم بضبطه بشكل منفصل بعد تغيير الحجم.  
- **سلامة الخيوط** – أنشئ كائن `PsDocument` جديد لكل خيط؛ مشاركة نفس الكائن قد تؤدي إلى نتائج غير متوقعة.
