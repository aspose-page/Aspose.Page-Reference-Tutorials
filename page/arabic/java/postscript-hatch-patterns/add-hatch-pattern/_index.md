# كيفية إضافة نمط التظليل في Java PostScript

## مقدمة
إذا كنت تعمل مع **Aspose.Page Java** وتتساءل **كيفية إضافة نمط التظليل** إلى مخرجات PostScript الخاصة بك، فإن أنماط التظليل هي حل سريع ومرن. في هذا البرنامج التعليمي سنستعرض **كيفية إضافة تصاميم التظليل** إلى مستند PostScript، نشرح لماذا هي مفيدة، ونقدم لك مثالًا كاملاً جاهزًا للتنفيذ. في النهاية، ستكون قادرًا على إنشاء أشكال ونصوص مملوءة بالتظليل ذات مظهر جذاب ببضع أسطر من Java.

## إجابات سريعة
- **ما المكتبة التي أحتاجها؟** Aspose.Page for Java (the “aspose page java” SDK).  
- **ما التأثير البصري الذي نضيفه؟** Hatch patterns (مثال: خطوط مائلة، تظليل متقاطع).  
- **هل أحتاج إلى ترخيص لتشغيل العينة؟** إصدار تجريبي مجاني يعمل للتطوير؛ يلزم وجود ترخيص للإنتاج.  
- **كم عدد أسطر الشيفرة؟** حوالي 70 سطرًا، مقسمة إلى خطوات واضحة.  
- **هل يمكنني استخدام نفس النهج لملفات PDF؟** نعم—Aspose.Page يدعم تنسيقات إخراج متعددة، بما في ذلك PDF.

## ما هو نمط التظليل؟
نمط التظليل هو تعبئة قائمة على المتجهات تتكون من خطوط أو أشكال مكررة تُنشئ تأثير نسيج. نظرًا لأنه مُعرّف رياضيًا، يتوسع النمط دون فقدان الجودة، مما يجعله مثاليًا للطباعة عالية الدقة والإخراج أحادي اللون.

## لماذا نستخدم أنماط التظليل مع Aspose.Page Java؟
Aspose.Page يدعم **أكثر من 10 تنسيقات إخراج** (بما في ذلك PostScript، PDF، EPS، SVG، و XPS) ويمكنه رسم تعبئة التظليل على مستندات تصل إلى **500 صفحة** دون تحميل الملف بالكامل في الذاكرة. هذا يعني حصولك على أداء سريع، استهلاك منخفض للذاكرة، ونتائج بصرية متسقة عبر جميع التنسيقات المدعومة.

## كيفية إضافة نمط التظليل – نظرة عامة
أنماط التظليل هي قوامات قائمة على المتجهات تُظهر بصورة نظيفة على أي دقة وتعمل جيدًا على الطابعات أحادية اللون. باستخدام Aspose.Page Java، يمكنك تطبيق هذه الأنماط على الأشكال، والمسارات، وحتى النص دون الحاجة للتعامل مع أوامر PostScript منخفضة المستوى.

- **مكتبة Aspose.Page for Java** – قم بتنزيل أحدث JAR من صفحة **Aspose.Page for Java download page** الرسمية [هنا](https://releases.aspose.com/page/java/).

## استيراد الحزم
تتضمن الاستيرادات أدناه فئات Java AWT القياسية للرسومات الأولية مثل الألوان، والحدود، والأشكال الهندسية، بالإضافة إلى فئات Aspose.Page التي توفر نموذج المستند، وتعريفات نمط التظليل، وخيارات الحفظ المطلوبة لإنشاء ملف PostScript.

```java
import java.awt.BasicStroke;
import java.awt.Color;
import java.awt.Font;
import java.awt.TexturePaint;
import java.awt.geom.Rectangle2D;
import java.io.FileOutputStream;
import com.aspose.eps.HatchPaintLibrary;
import com.aspose.eps.HatchStyle;
import com.aspose.eps.PsDocument;
import com.aspose.eps.device.PsSaveOptions;
```

## ما هي فئة `Document`؟
فئة `Document` هي الكائن الأعلى مستوى في Aspose.Page والذي يمثل ملف PostScript واحد في الذاكرة. جميع عمليات الرسم تُجرى عبر هذا الكائن.

## كيفية إعداد تدفق الإخراج؟
للكتابة إلى الإخراج، أنشئ `FileOutputStream` يشير إلى مسار الملف المطلوب؛ هذا التدفق يتعامل مع كتابة البايتات منخفضة المستوى. `PsSaveOptions` يضبط كيفية حفظ المستند، بما في ذلك حجم الصفحة والضغط. ثم قم بإنشاء كائن `Document` باستخدام كائن `PsSaveOptions` الذي يحدد حجم الصفحة، والضغط، وإعدادات PostScript الأخرى.

```java
// The path to the documents directory.
String dataDir = "Your Document Directory";
// Create output stream for PostScript document
FileOutputStream outPsStream = new FileOutputStream(dataDir + "AddHatchPattern_outPS.ps");
// Create save options with A4 size
PsSaveOptions options = new PsSaveOptions();
// Create new PS Document with the page opened
PsDocument document = new PsDocument(outPsStream, options, false);
int x0 = 20;
int y0 = 100;
int squareSide = 32;
int width = 500;
int sumX = 0;
```

## كيفية حفظ حالة الرسومات وترجمة الأصل؟
حفظ حالة الرسومات يلتقط مصفوفة التحويل الحالية، ومنطقة القطع، وسمات الرسم، مما يسمح لك بالعودة لاحقًا. بعد الحفظ، استدعِ `translate(x, y)` على كائن الرسومات لتحريك الأصل إلى موقع مناسب لرسم شبكة مربعات التظليل.

```java
document.writeGraphicsSave();
document.translate(x0, y0);
```

## كيفية إنشاء مربع قابل لإعادة الاستخدام لكل نمط؟
`Rectangle2D` يمثل شكلًا مستطيلًا يُحدد بموقعه وحجمه. بإنشاء نسخة واحدة تتطابق مع أبعاد الخلية، يمكنك إعادة استخدامها لكل مربع مملوء بالتظليل، مما يقلل من تخصيص الكائنات ويحافظ على كفاءة حلقة الرسم.

```java
Rectangle2D.Float square = new Rectangle2D.Float(0, 0, squareSide, squareSide);
```

## كيفية إعداد قلم لتحديد حدود مربع النمط؟
`BasicStroke` يصف سمك الحد، ونمط الشرط، ونهايات القمم للأشكال المتجهية. استخدام `BasicStroke` بسمك نقطتين يوفر حدًا واضحًا حول كل خلية مملوءة بالتظليل، مما يضمن فصل التعبئة بصريًا عن المربعات المجاورة.

```java
BasicStroke stroke = new BasicStroke(2);
```

## كيفية التكرار عبر أنماط التظليل؟
`HatchStyle` هو تعداد يدرج جميع أنماط التظليل المعرفة مسبقًا مثل الأنماط القطرية، المتقاطعة، والنقطية. التكرار عبر `HatchStyle.values()` يتيح لك تطبيق كل نمط على حدة، ملء المستطيل بـ `HatchBrush`، ثم رسم حدوده.

```java
HatchStyle[] hatchStyles = HatchStyle.values();
for (int i = 0; i < hatchStyles.length; i++) {
    // ... (continue with the provided code)
}
```

## كيفية استعادة حالة الرسومات بعد الرسم؟
استدعاء `restore()` على كائن الرسومات يعيد مصفوفة التحويل وإعدادات الرسم إلى الحالة التي تم حفظها مسبقًا، مما يمنع تراكم التحويلات أو التكبير من التأثير على عمليات الرسم اللاحقة. هذا يضمن أن المحتوى اللاحق يبدأ من نظام الإحداثيات الأصلي ويستخدم السمات الافتراضية.

```java
document.writeGraphicsRestore();
```

## كيفية ملء النص بنمط التظليل؟
`TextFragment` يمثل قطعة نص يمكن وضعها وتنسيقها بشكل مستقل. من خلال تعيين `HatchBrush` بنمط `HatchStyle` المختار إلى تعبئة القطعة، يتم رسم أحرف النص باستخدام نسيج التظليل بدلاً من لون صلب.

```java
TexturePaint paint = HatchPaintLibrary.getHatchTexturePaint(HatchStyle.DiagonalCross, Color.RED, Color.YELLOW);
Font font = new Font("Arial", Font.BOLD, 96);
document.fillAndStrokeText("ABC", font, 200, 320, paint, Color.BLACK, stroke);
```

## كيفية تحديد حدود النص بنمط تظليل مختلف؟
`HatchBrush` يمكن أيضًا استخدامه للتحديد. لرسم حد، عيّن حد القطعة إلى `HatchBrush` بنمط `HatchStyle` مختلف (مثال: تظليل 70 ٪) وزد عرض الحد عبر `setStrokeWidth`. هذا يرسم حدود النص بنمط تظليل خاص به مع الحفاظ على الجزء المملوء.

```java
paint = HatchPaintLibrary.getHatchTexturePaint(HatchStyle.Percent70, Color.BLUE, Color.WHITE);
document.outlineText("ABC", font, 200, 420, paint, new BasicStroke(5));
```

## كيفية إغلاق وحفظ المستند؟
`document.save()` يكتب المستند الموجود في الذاكرة إلى تدفق الإخراج المحدد. بعد إكمال جميع أوامر الرسم، استدعِ هذه الطريقة ثم أغلق `FileOutputStream` لتحرير موارد النظام وضمان تفريغ الملف بشكل صحيح إلى القرص.

```java
document.closePage();
document.save();
```

اتبع هذه الخطوات، وستحصل على ملف PostScript يعرض مجموعة كاملة من أنماط التظليل المطبقة على الأشكال والنصوص — كل ذلك مدعوم من **aspose page java**.

## المشكلات الشائعة والنصائح
- **أخطاء مسار الملف** – تأكد من أن `dataDir` ينتهي بفاصل الملفات المناسب (`/` أو `\`).  
- **ألوان غير مدعومة** – قد لا تتعامل بعض مفسرات PostScript القديمة مع بعض مساحات الألوان؛ استخدم RGB الأساسي لضمان أقصى توافق.  
- **تحذيرات الترخيص** – تشغيل العينة بدون ترخيص صالح سيضيف علامة مائية إلى الإخراج.
