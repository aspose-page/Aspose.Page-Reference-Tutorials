## How to rotate elements java using Aspose.Page?

Load the target drawable object, call its `setRotation(double angle)` method (angle in degrees), and then render the page. `setRotation(double angle)` sets the rotation angle of the drawable in degrees. Rotation is applied around the object's origin point, so you may combine it with a translation matrix to pivot around a custom centre. This two‑step pattern lets you rotate charts, images, or text blocks with a single API call.
