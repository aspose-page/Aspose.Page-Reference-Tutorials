# Aspose.Page for .NET ile Postscript'ten PDF'ye Dönüştürme

## Giriş

Eğer **postscript'ten pdf'ye dönüşüm**'ı hızlı ve güvenilir bir şekilde yapmanız gerekiyorsa, Aspose.Page for .NET temiz, kod‑öncelikli bir API sunar ve işi sizin için halleder. Bu öğreticide, **PostScript'i nasıl dönüştüreceğinizi** gösteren gerçek bir örnek üzerinden ilerleyeceğiz, özel yazı tipleri ekleyecek ve sonucu dağıtabileceğiniz veya arşivleyebileceğiniz bir PDF belgesi olarak kaydedeceksiniz. Ayrıca geliştiricilerin batch işleri, özel yazı tipi yönetimi ve yüksek doğruluklu renderleme için Aspose.Page'i neden tercih ettiğini .NET ekosistemi içinde kalırken göreceksiniz.

## Hızlı Yanıtlar
- **Dönüşümü hangi kütüphane yönetir?** Aspose.Page for .NET – harici bağımlılıkları olmayan yerel bir .NET kütüphanesidir.  
- **Kendi yazı tiplerimi ekleyebilir miyim?** Evet – `AdditionalFontsFolders` seçeneğini kendi özel yazı tipi dizininize işaret edecek şekilde ayarlayın.  
- **Batch dönüşüm mümkün mü?** Kesinlikle; sadece bir PostScript dosyaları koleksiyonu üzerinde döngü yapın ve aynı dönüşüm mantığını yeniden kullanın.  
- **Üretim için lisansa ihtiyacım var mı?** Üretim için ticari bir lisans gereklidir; değerlendirme için ücretsiz bir deneme sürümü mevcuttur.  
- **Hangi .NET sürümleri destekleniyor?** .NET Framework 4.5+, .NET Core 3.1+, .NET 5/6/7+.

`AdditionalFontsFolders` özelliği, renderleme sırasında kullanılacak özel yazı tiplerini içeren ek dizinleri belirtmenizi sağlar.

## PostScript'i PDF'ye Dönüştürme Nedir?

PostScript'i PDF'ye dönüştürmek, bir sayfa‑tanımlama dili (PostScript) alıp onu taşınabilir, yaygın olarak desteklenen PDF formatına render etmek anlamına gelir. Bu, eski baskı dosyaları aldığınızda, belgeleri arşivlemeniz gerektiğinde veya tarayıcılarda ekstra eklentiler olmadan görüntülemek istediğinizde faydalıdır.

## Neden Aspose.Page for .NET Kullanmalı?

Aspose.Page for .NET, dış araçlar kullanmadan PostScript dosyalarını PDF'ye dönüştüren tam yönetilen bir çözüm sunar. Yüksek doğruluklu renderleme sağlar, özel yazı tiplerini destekler ve desteklenen herhangi bir .NET çalışma zamanında çalışır, bu da dağıtımı basit ve güvenilir kılar. Kütüphane çok iş parçacıklı güvenli (thread‑safe) olup, hataları zarif bir şekilde ele alır ve sunucu ortamlarında batch işleme için ölçeklenebilir.  
- **Harici bağımlılık yok** – kütüphane tek bir NuGet paketi olarak gelir, dağıtım karmaşıklığını azaltır.  
- **Yazı tipleri üzerinde tam kontrol** – `AdditionalFontsFolders` özelliğini kullanarak **10 özel yazı tipi klasörüne** kadar sağlayabilirsiniz, bu da her glifin tam olarak istediğiniz gibi görünmesini sağlar.  
- **Güçlü hata yönetimi** – API, kullanılabilir bir PDF üretmeye devam ederken küçük render hatalarını bastırabilir; ayrıca dönüşüm sonrası inceleme için **500'e kadar istisna** içeren bir koleksiyon sunar.  
- **Batch işleme için ölçeklenebilir** – dönüşüm motoru thread‑safe'dir ve tipik bir 8 çekirdekli sunucuda **yüzlerce dosyayı aynı anda** işleyebilir, 200 sayfalık bir PostScript dosyasını 2 saniyeden kısa sürede işler.

## Ad Alanlarını İçe Aktarma

`using` yönergeleri, temel dönüşüm sınıflarına erişmenizi sağlar. Aşağıdaki satırları C# kaynak dosyanızın en üstüne yerleştirin:

```csharp
using Aspose.Page.EPS;
using Aspose.Page.EPS.Device;
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
```

## Adım 1: Akışları Başlatma

PostScript ve PDF dosyaları için giriş ve çıkış akışlarını başlatarak başlayın. `"Your Document Directory"` ifadesini `.ps` dosyalarınızı içeren gerçek klasörle değiştirin.

```csharp
// The path to the documents directory.
string dataDir = "Your Document Directory";
// Initialize PDF output stream
System.IO.FileStream pdfStream = new System.IO.FileStream(dataDir + "outputPDF_out.pdf", System.IO.FileMode.Create, System.IO.FileAccess.Write);
// Initialize PostScript input stream
System.IO.FileStream psStream = new System.IO.FileStream(dataDir + "input.ps", System.IO.FileMode.Open, System.IO.FileAccess.Read);
PsDocument document = new PsDocument(psStream);
```

## Adım 2: Dönüşüm Seçeneklerini Ayarlama

Dönüşüm sürecini kontrol etmek için bir `Options` nesnesi oluşturun ve gerekli parametreleri yapılandırın. Bu örnekte, kaynak kritik olmayan sorunlar içeriyor olsa bile dönüşümün devam etmesi için hata bastırmayı etkinleştiriyoruz.

`Options` sınıfı, hata yönetimi ve yazı tipi klasörü yapılandırması gibi dönüşüm ayarlarını kapsüller.

```csharp
// If you want to convert Postscript file despite of minor errors set this flag
bool suppressErrors = true;
// Initialize options object with necessary parameters.
PdfSaveOptions options = new PdfSaveOptions(suppressErrors);
// If you want to add a special folder where fonts are stored. Default fonts folder in OS is always included.
options.AdditionalFontsFolders = new string[] { @"{FONT_FOLDER}" };
```

> **Pro ipucu:** Host işletim sistemine yüklü olmayan **özel yazı tipleri pdf** dosyalarını eklemeniz gerektiğinde `AdditionalFontsFolders` özelliğini kullanın.

## Adım 3: PDF Aygıtını Başlatma

Render edilen sayfaları alacak bir PDF aygıtı oluşturun. İsteğe bağlı olarak sayfa boyutunu, görüntü çözünürlüğünü ve diğer render ipuçlarını belirtebilirsiniz.

`PdfDevice` sınıfı render edilen sayfaları alır ve bir PDF akışına yazar.

```csharp
// Default page size is 595x842 and it is not mandatory to set it in PdfDevice
Aspose.Page.EPS.Device.PdfDevice device = new Aspose.Page.EPS.Device.PdfDevice(pdfStream);
// But if you need to specify size and image format use the following line
//Aspose.Page.EPS.Device.PdfDevice device = new Aspose.Page.EPS.Device.PdfDevice(pdfStream, new System.Drawing.Size(595, 842));
```

## Adım 4: Belgeyi Kaydetme

Cihaz üzerindeki `Save` metodunu çağırın, çıkış akışını ve daha önce yapılandırdığınız seçenekleri parametre olarak geçin.

Cihaz üzerindeki `Save` metodu, belirtilen seçenekleri kullanarak render edilen içeriği çıkış akışına yazar.

```csharp
try
{
    document.Save(device, options);
}
finally
{
    psStream.Close();
    pdfStream.Close();
}
```

## Adım 5: Hataları İnceleme

Dönüşümden sonra, yakalanan istisnalar üzerinden döngü yaparak hangi küçük sorunların bastırıldığını anlayın. Bu adım, dönüşüm sonrası denetim gerektiği büyük ölçekli batch işler için çok önemlidir.

`Exceptions` koleksiyonu, dönüşüm sırasında yakalanan kritik olmayan hataları içerir.

```csharp
// Review errors
if (suppressErrors)
{
    foreach (Exception ex in options.Exceptions)
    {
        Console.WriteLine(ex.Message);
    }
}
```
