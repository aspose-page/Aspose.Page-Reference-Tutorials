## Aspose Page XPS 是什么？

Aspose Page XPS 是一个 Java API，能够创建和操作 XPS 文件。它将 XML Paper Specification 格式抽象为高级对象，使您可以专注于设计而非标记。

## 为什么使用 Aspose Page XPS 添加渐变？

- **Consistent rendering** 在所有 XPS 查看器上保持一致 – 在 Windows、macOS 和 Linux 上实现 99.9% 的保真度。  
- **Device‑independent vector graphics** 设备无关的矢量图形，可无像素化放大，支持高达 500 MB 的文档而无需将整个文件加载到内存中。  
- **Simple, fluent API** – 您可以用不到五个方法调用就添加渐变。  
- **Performance‑optimized** – 在标准 2.5 GHz CPU 上处理包含混合渐变的 200 页 XPS，仅需不到 2 秒。

**Q: 我可以在商业项目中使用这些渐变技术吗？**
