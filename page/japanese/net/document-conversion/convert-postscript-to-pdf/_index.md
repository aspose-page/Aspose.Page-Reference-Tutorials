# Aspose.Page for .NET を使用した Postscript から PDF への変換

## はじめに

迅速かつ確実に **postscript to pdf conversion** が必要な場合、Aspose.Page for .NET はクリーンなコードファースト API を提供し、重い処理を代行します。このチュートリアルでは、実際の例を通じて **PostScript** ファイルの変換方法、カスタムフォントの追加方法、配布やアーカイブに利用できる PDF ドキュメントとして保存する方法を詳しく解説します。また、開発者がバッチジョブ、カスタムフォント処理、高忠実度レンダリングのために Aspose.Page を選択する理由も、.NET エコシステム内で完結する点と共に紹介します。

## クイック回答
- **変換を処理するライブラリは何ですか？** Aspose.Page for .NET – 外部依存性のないネイティブ .NET ライブラリです。  
- **独自のフォントを追加できますか？** はい – `AdditionalFontsFolders` オプションを設定して、カスタムフォント ディレクトリを指すようにします。  
- **バッチ変換は可能ですか？** もちろんです。PostScript ファイルのコレクションをループし、同じ変換ロジックを再利用するだけです。  
- **本番環境でライセンスが必要ですか？** 商用ライセンスが本番環境で必要です。評価用の無料トライアルも利用可能です。  
- **サポートされている .NET バージョンはどれですか？** .NET Framework 4.5+、.NET Core 3.1+、.NET 5/6/7+。

`AdditionalFontsFolders` プロパティを使用すると、レンダリング時に使用するカスタムフォントを含む追加ディレクトリを指定できます。

## PostScript を PDF に変換するとは？

PostScript を PDF に変換するとは、ページ記述言語（PostScript）を取得し、広くサポートされているポータブルな PDF 形式にレンダリングすることを意味します。これは、レガシーな印刷ファイルを受け取ったときや、文書をアーカイブしたいとき、またはプラグインなしでブラウザに表示したいときに便利です。

## なぜ Aspose.Page for .NET を使用するのか？

Aspose.Page for .NET は、外部ツールを使用せずに PostScript ファイルを PDF に変換する完全マネージド ソリューションを提供します。高忠実度のレンダリングを実現し、カスタムフォントをサポートし、任意のサポート対象 .NET ランタイム上で動作するため、デプロイがシンプルで信頼性があります。ライブラリはスレッドセーフで、エラーを優雅に処理し、サーバー環境でのバッチ処理にもスケールします。  
- **外部依存性ゼロ** – ライブラリは単一の NuGet パッケージとして提供され、デプロイの複雑さを軽減します。  
- **フォントの完全な制御** – `AdditionalFontsFolders` プロパティを使用して最大 **10 個** のカスタムフォントフォルダーを指定でき、すべての字形が意図通りに表示されます。  
- **堅牢なエラーハンドリング** – API はマイナーなレンダリングエラーを抑制しつつ、利用可能な PDF を生成します。また、変換後のレビュー用に最大 **500 件** の例外コレクションを提供します。  
- **バッチ処理にスケーラブル** – 変換エンジンはスレッドセーフで、一般的な 8 コアサーバー上で **数百ファイル** を同時に処理でき、200 ページの PostScript ファイルを 2 秒未満で処理します。

## 名前空間のインポート

`using` ディレクティブにより、コア変換クラスにアクセスできます。以下の行を C# ソース ファイルの先頭に配置してください。

```csharp
using Aspose.Page.EPS;
using Aspose.Page.EPS.Device;
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
```

## 手順 1: ストリームの初期化

PostScript と PDF ファイル用の入力および出力ストリームを初期化します。`"Your Document Directory"` を実際の `.ps` ファイルが格納されているフォルダーに置き換えてください。

```csharp
// The path to the documents directory.
string dataDir = "Your Document Directory";
// Initialize PDF output stream
System.IO.FileStream pdfStream = new System.IO.FileStream(dataDir + "outputPDF_out.pdf", System.IO.FileMode.Create, System.IO.FileAccess.Write);
// Initialize PostScript input stream
System.IO.FileStream psStream = new System.IO.FileStream(dataDir + "input.ps", System.IO.FileMode.Open, System.IO.FileAccess.Read);
PsDocument document = new PsDocument(psStream);
```

## 手順 2: 変換オプションの設定

変換プロセスを制御するために `Options` オブジェクトを作成し、必要なパラメータを構成します。この例では、ソースに致命的でない問題があっても変換を継続できるようにエラー抑制を有効にしています。

`Options` クラスは、エラーハンドリングやフォント フォルダー構成などの変換設定をカプセル化します。

```csharp
// If you want to convert Postscript file despite of minor errors set this flag
bool suppressErrors = true;
// Initialize options object with necessary parameters.
PdfSaveOptions options = new PdfSaveOptions(suppressErrors);
// If you want to add a special folder where fonts are stored. Default fonts folder in OS is always included.
options.AdditionalFontsFolders = new string[] { @"{FONT_FOLDER}" };
```

> **プロのコツ:** ホスト OS にインストールされていない **add custom fonts pdf** ファイルを使用する必要がある場合は、必ず `AdditionalFontsFolders` プロパティを利用してください。

## 手順 3: PDF デバイスの初期化

レンダリングされたページを受け取る PDF デバイスを作成します。ページサイズ、画像解像度、その他のレンダリングヒントをオプションで指定できます。

`PdfDevice` クラスはレンダリングされたページを受け取り、PDF ストリームに書き込みます。

```csharp
// Default page size is 595x842 and it is not mandatory to set it in PdfDevice
Aspose.Page.EPS.Device.PdfDevice device = new Aspose.Page.EPS.Device.PdfDevice(pdfStream);
// But if you need to specify size and image format use the following line
//Aspose.Page.EPS.Device.PdfDevice device = new Aspose.Page.EPS.Device.PdfDevice(pdfStream, new System.Drawing.Size(595, 842));
```

## 手順 4: ドキュメントの保存

デバイスの `Save` メソッドを呼び出し、出力ストリームと先に構成したオプションを渡します。

デバイスの `Save` メソッドは、指定されたオプションを使用してレンダリングされたコンテンツを出力ストリームに書き込みます。

```csharp
try
{
    document.Save(device, options);
}
finally
{
    psStream.Close();
    pdfStream.Close();
}
```

## 手順 5: エラーの確認

変換後、捕捉された例外を列挙して、どのようなマイナー問題が抑制されたかを確認します。このステップは、大規模なバッチジョブで変換後の監査が必要な場合に重要です。

`Exceptions` コレクションには、変換中に捕捉された非致命的エラーが含まれます。

```csharp
// Review errors
if (suppressErrors)
{
    foreach (Exception ex in options.Exceptions)
    {
        Console.WriteLine(ex.Message);
    }
}
```

### よくある落とし穴と回避策

| 問題 | 発生理由 | 対策 |
|------|----------|------|
| フォントが表示されない | カスタムフォントが OS のフォントフォルダーにない | `options.AdditionalFontsFolders` にフォルダー パスを追加する |
| ページが欠落している | 入力 PostScript にエラーがある | `suppressErrors = true` を設定して変換を続行し、`options.Exceptions` を確認する |
| 出力ファイルがロックされている | ストリームが正しく閉じられていない | `finally` ブロックで `psStream` と `pdfStream` の両方を必ず閉じる（例参照） |
