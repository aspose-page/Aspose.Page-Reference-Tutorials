## Aspose Page XPS란?

Aspose Page XPS는 XPS 파일의 생성 및 조작을 가능하게 하는 Java API입니다. XML Paper Specification 형식을 고수준 객체로 추상화하여 마크업이 아닌 디자인에 집중할 수 있게 해줍니다.

## 왜 Aspose Page XPS를 사용해 그라디언트를 추가하나요?

- **일관된 렌더링** 모든 XPS 뷰어에서 – Windows, macOS, Linux 전반에 걸쳐 99.9% 정확도.  
- **디바이스 독립적인 벡터 그래픽** 픽셀화 없이 확장 가능하며, 전체 파일을 메모리에 로드하지 않고도 500 MB까지 문서를 지원합니다.  
- **간단하고 유창한 API** – 다섯 번 미만의 메서드 호출로 그라디언트를 추가할 수 있습니다.  
- **성능 최적화** – 표준 2.5 GHz CPU에서 혼합 그라디언트가 포함된 200페이지 XPS를 처리하는 데 2초 미만 걸립니다.

### 대각선 그라디언트: 시각적 우수성 향상

### 수평 그라디언트: 원활한 통합 공개

### 수직 그라디언트: 손쉽게 시각적 매력 향상
#### [Java XPS에서 수직 그라디언트 추가](./vertical/)

`LinearGradientBrush` 클래스는 도형에 적용할 수 있는 선형 그라디언트 채우기를 나타냅니다. 수직 그라디언트는 색상을 위에서 아래로 서서히 변하게 하여 세련된 느낌을 줍니다. 단계별 튜토리얼에서는 90° 방향의 `LinearGradientBrush`를 생성하고, 페이지 전체에 걸친 사각형에 적용한 뒤, 여러 페이지에서 브러시를 재사용하여 파일 크기를 최소화하는 방법을 시연합니다.
