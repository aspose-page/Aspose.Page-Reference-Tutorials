# Aspose.Page .NET – 모양 그리기

## 소개

Aspose.Page .NET은 개발자가 .NET에서 PostScript(PS) 또는 XPS 파일을 보내면서 더 많은 도형을 그릴 수 있도록 해줄 것입니다. 이 가이드에서는 원, 타원, 세트 등 다양한 도형을 추가하는 방법을 추가 **.NET로 도형을 추가하는 방법**을 스타일로 표시합니다. Aspose.Page .NET으로 도형을 추가하는 것이 왜 더 강력하고 커지는지 함께 살펴보세요.

## 빠른 답변
- **Aspose.Page .NET의 기능은 무엇입니까?** 기하학적 모양 그리기를 포함하여 PS 및 XPS 문서를 프로그래밍 방식으로 생성하고 조작할 수 있습니다.
- **어떤 모양을 그릴 수 있나요?** 원, 타원, 직사각형 및 사용자 정의 경로.
- **라이센스가 필요합니까?** 무료 평가판을 사용할 수 있습니다. 프로덕션 용도로 사용하려면 상업용 라이센스가 필요합니다.
- **어떤 .NET 버전이 지원됩니까?** .NET Framework 4.5+, .NET Core 3.1+, .NET 5/6/7.
- **샘플 코드가 있습니까?** 예 - 링크된 각 튜토리얼은 즉시 실행 가능한 예제를 제공합니다.

## Aspose.Page .NET이란 무엇입니까?
Aspose.Page .NET은 Adobe 도구 없이도 PostScript와 XPS 문서를 생성·편집할 수 있을 정도로 .NET 클래스입니다. 도형 그리기, 색상·그라디언트 적용, 페이지 배열 관리 등을 복잡한 코드로 처리할 수 있는 풍부한 API를 제공합니다.

## Aspose.Page를 사용하여 .NET 모양을 그리는 이유는 무엇입니까?
- **교차 형식 지원:** 한 번 작성하면 PS 또는 XPS로 출력됩니다.
- **고품질:** 벡터 그래픽은 어떤 규모에서도 품질을 유지합니다.
- **외부 종속성 없음:** 순수 .NET, 네이티브 라이브러리가 필요하지 않습니다.
- **개발자 친화적인 API:** 직관적인 메서드와 명확한 이름 지정으로 .NET 애플리케이션에서 **도형을 쉽게 그릴 수 있습니다.**

## 자주 묻는 질문

**질문: Aspose.Page .NET을 상업용 애플리케이션에서 사용할 수 있나요?**
답변: 네, 유효한 Aspose 라이선스가 있으면 상업적으로 사용할 수 있습니다. 평가를 위해 무료 평가판을 이용할 수 있습니다.

**질문: 네이티브 구성 요소를 설치해야 하나요?**
답변: 아니요, Aspose.Page .NET은 순수 관리형 라이브러리이므로 NuGet 패키지만 참조하면 됩니다.

**질문: 같은 페이지에 도형과 텍스트를 함께 사용할 수 있나요?**
답변: 물론입니다. API를 사용하면 도형을 그린 다음 필요에 따라 Z축 순서를 제어하여 텍스트 개체를 추가할 수 있습니다.

**질문: 도형이 많은 대용량 문서는 어떻게 처리하나요?**
답변: 스트림 버퍼링을 사용하는 `Document.Save` 오버로드를 사용하고 메모리 사용량을 낮추기 위해 페이지를 분할하는 것을 고려해 보세요.

**질문: Aspose.Page는 투명도와 그라디언트를 지원하나요?**
답변: 네, PS 및 XPS API 모두 풍부한 시각 효과를 위한 그라디언트 브러시와 알파 합성 기능을 제공합니다.
