## Cos'è Aspose Page Conversion?
Aspose Page Conversion è la funzionalità di Aspose.Page che trasforma i file PostScript e XPS in documenti PDF.

L'API preserva caratteri, grafica e layout consentendo di impostare dimensione pagina, compressione e metadati in modo programmatico.

Elabora file fino a diverse centinaia di pagine in meno di un secondo per file su tipico hardware server.

## Domande frequenti

**Q: Come converto PostScript in PDF programmaticamente?**  
`PostScriptDocument` is a class that loads a PostScript file and enables conversion to other formats.  
A: Usa la classe `PostScriptDocument` di Aspose.Page, carica il file .ps e chiama il metodo `Save` con il formato PDF.

**Q: Esiste un limite alla dimensione dei file XPS che posso convertire?**  
A: Non c'è un limite rigido, ma documenti XPS molto grandi potrebbero richiedere un'allocazione di memoria maggiore o una conversione in streaming.

**Q: Posso personalizzare i metadati PDF durante la conversione?**  
`PdfDocument` is a class representing a PDF file, allowing access to its metadata and content.  
A: Sì – dopo la conversione puoi modificare la proprietà `Info` dell'oggetto `PdfDocument` per impostare titolo, autore e altri metadati.

**Q: È necessaria una licenza separata per ogni tipo di conversione?**  
A: No – una singola licenza Aspose.Page copre tutti i formati supportati, inclusi PostScript e XPS.

**Q: Cosa succede se il file sorgente contiene grafica non supportata?**  
A: Aspose.Page renderà gli elementi supportati e ignorerà quelli sconosciuti, registrando avvisi che potrai esaminare.
