# XPS दस्तावेज़ .NET बनाएं – Aspose.Page के साथ आयत जोड़ें

## परिचय

इस ट्यूटोरियल में आप सीखेंगे कि **create XPS document .NET** कैसे बनाएं और Aspose.Page for .NET का उपयोग करके उसके भीतर एक आयत कैसे बनाएं। चाहे आप रिपोर्टिंग इंजन, प्रिंटेबल इनवॉइस, या कस्टम ग्राफ़िक्स लेयर बना रहे हों, प्रोग्रामेटिक रूप से XPS फ़ाइलें जनरेट करने की क्षमता आपको लेआउट और फिडेलिटी पर पूर्ण नियंत्रण देती है। नीचे दिए गए चरणों का पालन करें और कुछ ही मिनटों में आपके पास उपयोग के लिए तैयार XPS फ़ाइल होगी।

## त्वरित उत्तर

- **मुख्य लक्ष्य क्या है?** Create an XPS document .NET and add a rectangle shape.  
- **कौनसी लाइब्रेरी आवश्यक है?** Aspose.Page for .NET (downloadable from the official site).  
- **परीक्षण के लिए मुझे लाइसेंस चाहिए?** विकास के लिए एक फ्री ट्रायल काम करता है; उत्पादन के लिए एक कमर्शियल लाइसेंस आवश्यक है।  
- **कौनसे .NET संस्करण समर्थित हैं?** .NET Framework 4.6+, .NET Core 3.1+, .NET 5/6/7.  
- **इम्प्लीमेंटेशन में कितना समय लगता है?** बेसिक आयत के लिए लगभग 5‑10 मिनट।

## Aspose.Page for .NET क्या है?

Aspose.Page for .NET एक हाई‑परफ़ॉर्मेंस, पूरी तरह मैनेज्ड API है जो डेवलपर्स को प्रोग्रामेटिक रूप से XPS (XML Paper Specification) दस्तावेज़ बनाना, संपादित करना और रेंडर करना सक्षम बनाता है, बिना बाहरी घटकों पर निर्भर हुए। यह शैप्स, टेक्स्ट और इमेजेज़ ड्रॉ करने के लिए एक समृद्ध ऑब्जेक्ट मॉडल प्रदान करता है, और कलर मैनेजमेंट, कंप्रेशन, और PDF कन्वर्ज़न जैसी उन्नत सुविधाओं का समर्थन करता है, जिससे यह विभिन्न दस्तावेज़ जनरेशन परिदृश्यों के लिए उपयुक्त बनता है।

## नेमस्पेस आयात करें

अपने .NET एप्लिकेशन में, Aspose.Page कार्यक्षमताओं का उपयोग करने के लिए आवश्यक नेमस्पेस शामिल करें।

```csharp
using Aspose.Page.XPS;
using Aspose.Page.XPS.XpsModel;
using System.Drawing;
```

## मैं .NET में XPS दस्तावेज़ में आयत कैसे जोड़ूँ?

XPS दस्तावेज़ लोड करें, एक `Graphics` ऑब्जेक्ट बनाएं, इच्छित आकार के साथ एक `RectangleF` परिभाषित करें, और `DrawRectangle` को कॉल करें। यह क्रम एक ही कोड लाइन में आयत बनाता है और स्वचालित रूप से DPI स्केलिंग को संभालता है। सामान्य A4‑साइज़ पेज़ के लिए, 200 × 100 pt आयत अतिरिक्त गणनाओं के बिना केंद्रित दिखाई देती है।

### चरण 1: डॉक्यूमेंट डायरेक्टरी सेट करें

```csharp
// ExStart:3
// The path to the documents directory.
string dataDir = "Your Document Directory";
// ExEnd:3
```

### चरण 2: नया XPS दस्तावेज़ बनाएं

```csharp
// ExStart:4
// Create new XPS Document
XpsDocument doc = new XpsDocument();
// ExEnd:4
```

### चरण 3: आयत जोड़ें

```csharp
// ExStart:5
// CMYK (blue) solid color stroked rectangle in the lower left
XpsPath path = doc.AddPath(doc.CreatePathGeometry("M 20,10 L 220,10 220,100 20,100 Z"));
path.Stroke = doc.CreateSolidColorBrush(
    doc.CreateColor(dataDir + "uswebuncoated.icc", 1.0f, 1.000f, 0.000f, 0.000f, 0.000f));
path.StrokeThickness = 12f;
// ExEnd:5
```

### चरण 4: दस्तावेज़ सहेजें

```csharp
// ExStart:6
// Save resultant XPS document
doc.Save(dataDir + "AddRectangleXPS_out.xps");
// ExEnd:6
```

बधाई हो! आपने Aspose.Page for .NET का उपयोग करके सफलतापूर्वक XPS दस्तावेज़ में एक आयत जोड़ दी है।

## सामान्य समस्याएँ और सुझाव

- **फ़ॉन्ट गायब:** सुनिश्चित करें कि आप जिन फ़ॉन्ट्स का संदर्भ दे रहे हैं वे सर्वर पर स्थापित हैं; अन्यथा Aspose.Page डिफ़ॉल्ट फ़ॉन्ट से बदल देता है, जिससे लेआउट बदल सकता है।  
- **बड़ी फ़ाइलें:** जब 200 MB से बड़ी फ़ाइलें जनरेट कर रहे हों, तो मेमोरी उपयोग कम करने के लिए `document.SaveOptions.Compress = true` कॉल करने पर विचार करें।  
- **कोऑर्डिनेट सिस्टम:** XPS पॉइंट्स (1/72 इंच) का उपयोग करता है। यदि आप स्क्रीन‑आधारित आयामों के साथ काम कर रहे हैं तो पिक्सेल को पॉइंट्स में बदलना याद रखें।
