# Conversão de PostScript para PDF com Aspose.Page para .NET

## Introdução

Se você precisa de **conversão de postscript para pdf** rápida e confiável, o Aspose.Page para .NET oferece uma API limpa, code‑first, que faz o trabalho pesado por você. Neste tutorial, percorreremos um exemplo do mundo real que mostra exatamente **como converter arquivos PostScript**, adicionar fontes personalizadas e salvar o resultado como um documento PDF que você pode distribuir ou arquivar. Você também verá por que os desenvolvedores escolhem o Aspose.Page para trabalhos em lote, manipulação de fontes personalizadas e renderização de alta fidelidade — tudo permanecendo dentro do ecossistema .NET.

## Respostas Rápidas
- **Qual biblioteca lida com a conversão?** Aspose.Page para .NET – uma biblioteca nativa .NET sem dependências externas.  
- **Posso adicionar minhas próprias fontes?** Sim – defina a opção `AdditionalFontsFolders` para apontar para o diretório de fontes personalizado.  
- **A conversão em lote é possível?** Absolutamente; basta percorrer uma coleção de arquivos PostScript e reutilizar a mesma lógica de conversão.  
- **Preciso de licença para produção?** Uma licença comercial é necessária para produção; um teste gratuito está disponível para avaliação.  
- **Quais versões do .NET são suportadas?** .NET Framework 4.5+, .NET Core 3.1+, .NET 5/6/7+.

A propriedade `AdditionalFontsFolders` permite especificar diretórios extras contendo fontes personalizadas a serem usadas durante a renderização.

## O que é converter PostScript para PDF?

Converter PostScript para PDF significa pegar uma linguagem de descrição de página (PostScript) e renderiz‑la no formato PDF portátil e amplamente suportado. Isso é útil quando você recebe arquivos de impressão legados, precisa arquivar documentos ou deseja exibi‑los em navegadores sem plugins adicionais.

Aspose.Page para .NET fornece uma solução totalmente gerenciada que converte arquivos PostScript para PDF sem ferramentas externas. ## Importar Namespaces

As diretivas `using` dão acesso às classes principais de conversão. Coloque as linhas a seguir no topo do seu arquivo‑fonte C#:

```csharp
using Aspose.Page.EPS;
using Aspose.Page.EPS.Device;
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
```

## Etapa 1: Inicializar Streams

Comece inicializando os streams de entrada e saída para os arquivos PostScript e PDF. Substitua `"Your Document Directory"` pela pasta real que contém seus arquivos `.ps`.

```csharp
// The path to the documents directory.
string dataDir = "Your Document Directory";
// Initialize PDF output stream
System.IO.FileStream pdfStream = new System.IO.FileStream(dataDir + "outputPDF_out.pdf", System.IO.FileMode.Create, System.IO.FileAccess.Write);
// Initialize PostScript input stream
System.IO.FileStream psStream = new System.IO.FileStream(dataDir + "input.ps", System.IO.FileMode.Open, System.IO.FileAccess.Read);
PsDocument document = new PsDocument(psStream);
```

## Etapa 2: Definir Opções de Conversão

Para controlar o processo de conversão, crie um objeto `Options` e configure os parâmetros necessários. Neste exemplo habilitamos a supressão de erros para que a conversão continue mesmo se a fonte contiver problemas não críticos.

A classe `Options` encapsula configurações de conversão como tratamento de erros e configuração de pastas de fontes.

```csharp
// If you want to convert Postscript file despite of minor errors set this flag
bool suppressErrors = true;
// Initialize options object with necessary parameters.
PdfSaveOptions options = new PdfSaveOptions(suppressErrors);
// If you want to add a special folder where fonts are stored. Default fonts folder in OS is always included.
options.AdditionalFontsFolders = new string[] { @"{FONT_FOLDER}" };
```

> **Dica profissional:** Use a propriedade `AdditionalFontsFolders` sempre que precisar **adicionar arquivos pdf de fontes personalizadas** que não estejam instalados no sistema operacional host.

## Etapa 3: Inicializar Dispositivo PDF

Crie um dispositivo PDF que receberá as páginas renderizadas. Você pode opcionalmente especificar tamanho da página, resolução de imagem e outras dicas de renderização.

A classe `PdfDevice` recebe páginas renderizadas e as grava em um stream PDF.

```csharp
// Default page size is 595x842 and it is not mandatory to set it in PdfDevice
Aspose.Page.EPS.Device.PdfDevice device = new Aspose.Page.EPS.Device.PdfDevice(pdfStream);
// But if you need to specify size and image format use the following line
//Aspose.Page.EPS.Device.PdfDevice device = new Aspose.Page.EPS.Device.PdfDevice(pdfStream, new System.Drawing.Size(595, 842));
```

## Etapa 4: Salvar o Documento

Chame o método `Save` no dispositivo, passando o stream de saída e as opções que você configurou anteriormente.

O método `Save` no dispositivo grava o conteúdo renderizado no stream de saída usando as opções especificadas.

```csharp
try
{
    document.Save(device, options);
}
finally
{
    psStream.Close();
    pdfStream.Close();
}
```

## Etapa 5: Revisar Erros

Após a conversão, itere sobre quaisquer exceções capturadas para entender quais problemas menores foram suprimidos. Esta etapa é essencial para trabalhos em lote de grande escala onde você precisa de uma auditoria pós‑execução.

A coleção `Exceptions` contém quaisquer erros não críticos capturados durante a conversão.

```csharp
// Review errors
if (suppressErrors)
{
    foreach (Exception ex in options.Exceptions)
    {
        Console.WriteLine(ex.Message);
    }
}
```

### Armadilhas Comuns & Como Evitá‑las

| Problema | Por que acontece | Solução |
|----------|------------------|---------|
| Fontes não exibidas | As fontes personalizadas não estão na pasta de fontes do SO | Adicione o caminho da pasta a `options.AdditionalFontsFolders` |
| Páginas ausentes | O PostScript de entrada tem erros | Defina `suppressErrors = true` para continuar a conversão e revise `options.Exceptions` |
| Arquivo de saída bloqueado | Stream não foi fechado corretamente | Sempre feche tanto `psStream` quanto `pdfStream` em um bloco `finally` (conforme mostrado) |
