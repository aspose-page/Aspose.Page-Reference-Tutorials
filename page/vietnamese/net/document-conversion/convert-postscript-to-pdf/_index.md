# Chuyển đổi Postscript sang PDF với Aspose.Page cho .NET

## Giới thiệu

Nếu bạn cần **postscript to pdf conversion** nhanh chóng và đáng tin cậy, Aspose.Page cho .NET cung cấp một API sạch, code‑first giúp bạn thực hiện công việc nặng. Trong hướng dẫn này, chúng tôi sẽ đi qua một ví dụ thực tế cho thấy chính xác **cách chuyển đổi PostScript** sang các tệp, thêm phông chữ tùy chỉnh và lưu kết quả dưới dạng tài liệu PDF mà bạn có thể phân phối hoặc lưu trữ. Bạn cũng sẽ thấy tại sao các nhà phát triển chọn Aspose.Page cho các công việc batch, xử lý phông chữ tùy chỉnh và render chất lượng cao — tất cả đều trong hệ sinh thái .NET.

## Câu trả lời nhanh

- **Thư viện nào xử lý việc chuyển đổi?** Aspose.Page cho .NET – một thư viện .NET gốc không có phụ thuộc bên ngoài.  
- **Tôi có thể thêm phông chữ của mình không?** Có – đặt tùy chọn `AdditionalFontsFolders` để chỉ tới thư mục phông chữ tùy chỉnh của bạn.  
- **Có thể thực hiện chuyển đổi batch không?** Chắc chắn; chỉ cần lặp qua một tập hợp các tệp PostScript và tái sử dụng cùng một logic chuyển đổi.  
- **Tôi có cần giấy phép cho môi trường sản xuất không?** Cần giấy phép thương mại cho môi trường sản xuất; bản dùng thử miễn phí có sẵn để đánh giá.  
- **Các phiên bản .NET nào được hỗ trợ?** .NET Framework 4.5+, .NET Core 3.1+, .NET 5/6/7+.

Thuộc tính `AdditionalFontsFolders` cho phép bạn chỉ định các thư mục bổ sung chứa phông chữ tùy chỉnh sẽ được sử dụng trong quá trình render.

## Chuyển đổi PostScript sang PDF là gì?

Chuyển đổi PostScript sang PDF có nghĩa là lấy một ngôn ngữ mô tả trang (PostScript) và render nó thành định dạng PDF di động, được hỗ trợ rộng rãi. Điều này hữu ích khi bạn nhận các tệp in cũ, cần lưu trữ tài liệu, hoặc muốn hiển thị chúng trong trình duyệt mà không cần plugin bổ sung.

## Nhập không gian tên

Các chỉ thị `using` cung cấp cho bạn quyền truy cập vào các lớp chuyển đổi cốt lõi. Đặt các dòng sau ở đầu tệp nguồn C# của bạn:

```csharp
using Aspose.Page.EPS;
using Aspose.Page.EPS.Device;
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
```

## Bước 1: Khởi tạo Streams

Bắt đầu bằng cách khởi tạo các luồng đầu vào và đầu ra cho các tệp PostScript và PDF. Thay thế `"Your Document Directory"` bằng thư mục thực tế chứa các tệp `.ps` của bạn.

```csharp
// The path to the documents directory.
string dataDir = "Your Document Directory";
// Initialize PDF output stream
System.IO.FileStream pdfStream = new System.IO.FileStream(dataDir + "outputPDF_out.pdf", System.IO.FileMode.Create, System.IO.FileAccess.Write);
// Initialize PostScript input stream
System.IO.FileStream psStream = new System.IO.FileStream(dataDir + "input.ps", System.IO.FileMode.Open, System.IO.FileAccess.Read);
PsDocument document = new PsDocument(psStream);
```

## Bước 2: Đặt tùy chọn chuyển đổi

Để kiểm soát quá trình chuyển đổi, tạo một đối tượng `Options` và cấu hình các tham số cần thiết. Trong ví dụ này, chúng tôi bật việc ẩn lỗi để quá trình chuyển đổi tiếp tục ngay cả khi nguồn chứa các vấn đề không quan trọng.

Lớp `Options` bao gồm các cài đặt chuyển đổi như xử lý lỗi và cấu hình thư mục phông chữ.

```csharp
// If you want to convert Postscript file despite of minor errors set this flag
bool suppressErrors = true;
// Initialize options object with necessary parameters.
PdfSaveOptions options = new PdfSaveOptions(suppressErrors);
// If you want to add a special folder where fonts are stored. Default fonts folder in OS is always included.
options.AdditionalFontsFolders = new string[] { @"{FONT_FOLDER}" };
```

> **Mẹo:** Sử dụng thuộc tính `AdditionalFontsFolders` bất cứ khi nào bạn cần **thêm các tệp phông chữ pdf** mà không được cài đặt trên hệ điều hành máy chủ.

## Bước 3: Khởi tạo thiết bị PDF

Tạo một thiết bị PDF sẽ nhận các trang đã render. Bạn có thể tùy chọn chỉ định kích thước trang, độ phân giải hình ảnh và các gợi ý render khác.

Lớp `PdfDevice` nhận các trang đã render và ghi chúng vào một luồng PDF.

```csharp
// Default page size is 595x842 and it is not mandatory to set it in PdfDevice
Aspose.Page.EPS.Device.PdfDevice device = new Aspose.Page.EPS.Device.PdfDevice(pdfStream);
// But if you need to specify size and image format use the following line
//Aspose.Page.EPS.Device.PdfDevice device = new Aspose.Page.EPS.Device.PdfDevice(pdfStream, new System.Drawing.Size(595, 842));
```

## Bước 4: Lưu tài liệu

Gọi phương thức `Save` trên thiết bị, truyền luồng đầu ra và các tùy chọn bạn đã cấu hình trước đó.

Phương thức `Save` trên thiết bị ghi nội dung đã render vào luồng đầu ra sử dụng các tùy chọn đã chỉ định.

```csharp
try
{
    document.Save(device, options);
}
finally
{
    psStream.Close();
    pdfStream.Close();
}
```

## Bước 5: Xem lại lỗi

Sau khi chuyển đổi, lặp qua bất kỳ ngoại lệ nào đã được ghi lại để hiểu những vấn đề nhỏ nào đã bị ẩn. Bước này rất cần thiết cho các công việc batch quy mô lớn, nơi bạn cần kiểm tra sau khi chạy.

Bộ sưu tập `Exceptions` chứa bất kỳ lỗi không quan trọng nào đã được ghi lại trong quá trình chuyển đổi.

```csharp
// Review errors
if (suppressErrors)
{
    foreach (Exception ex in options.Exceptions)
    {
        Console.WriteLine(ex.Message);
    }
}
```

### Các lỗi thường gặp & Cách tránh

| Vấn đề | Nguyên nhân | Cách khắc phục |
|-------|----------------|-----|
| Phông chữ không hiển thị | Phông chữ tùy chỉnh không có trong thư mục phông chữ của hệ điều hành | Thêm đường dẫn thư mục vào `options.AdditionalFontsFolders` |
| Trang bị thiếu | PostScript đầu vào có lỗi | Đặt `suppressErrors = true` để tiếp tục chuyển đổi và xem xét `options.Exceptions` |
| Tệp đầu ra bị khóa | Luồng không được đóng đúng cách | Luôn đóng cả `psStream` và `pdfStream` trong khối `finally` (như ví dụ) |
