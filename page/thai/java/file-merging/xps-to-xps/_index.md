## การรวมไฟล์ XPS คืออะไร?

## นำเข้าแพ็กเกจ
คลาส `XpsDocument` แทนไฟล์ XPS ในหน่วยความจำและให้เมธอดสำหรับโหลด, จัดการ, และบันทึกเอกสาร XPS  

```java
import java.io.FileOutputStream;

import com.aspose.xps.XpsDocument;
```

## ขั้นตอนที่ 1: ตั้งค่าโปรเจกต์ของคุณ
สร้างโปรเจกต์ Java ใหม่ใน IDE ที่คุณเลือกและเพิ่มไฟล์ JAR ของ Aspose.Page ไปยังเส้นทางการสร้างของโปรเจกต์ ซึ่งจะทำให้คอมไพเลอร์สามารถหาคลาส `XpsDocument` ได้

## ขั้นตอนที่ 2: เริ่มต้นสตรีมเอาต์พุต XPS
ตั้งค่าสตรีมเอาต์พุตสำหรับไฟล์ XPS ที่รวมกัน ระบุไดเรกทอรีที่คุณต้องการบันทึกไฟล์ที่รวมแล้ว

```java
String dataDir = "Your Document Directory";
FileOutputStream outStream = new FileOutputStream(dataDir + "mergedXPSfiles.xps");
```

> **เคล็ดลับ:** ใช้เส้นทางแบบเต็มระหว่างการพัฒนาเพื่อหลีกเลี่ยง `FileNotFoundException`, จากนั้นสลับไปใช้เส้นทางแบบสัมพันธ์สำหรับการผลิต

## ขั้นตอนที่ 3: โหลดไฟล์ XPS แรก
โหลดไฟล์ XPS แรกที่ทำหน้าที่เป็นฐานสำหรับการรวม

```java
XpsDocument document = new XpsDocument(dataDir + "input.xps");
```

คุณสมบัติของเอกสารแรก (เช่น ขนาดหน้าและแนวตั้ง) จะกลายเป็นค่าเริ่มต้นสำหรับไฟล์ที่รวมสุดท้าย

## ขั้นตอนที่ 4: สร้างอาร์เรย์ของไฟล์ XPS
เตรียมอาร์เรย์ของไฟล์ XPS ที่คุณต้องการรวมกับไฟล์แรก

```java
String[] filesForMerge = new String[] { dataDir + "Demo.xps", dataDir + "sample.xps" };
```

คุณสามารถเพิ่มเส้นทางไฟล์ได้ตามต้องการ; อาร์เรย์สามารถสร้างแบบไดนามิกจากการแสดงรายการไดเรกทอรีหากต้องการ

## ขั้นตอนที่ 5: รวมและบันทึก
ดำเนินการรวมและบันทึกผลลัพธ์ไปยังสตรีมเอาต์พุตที่ระบุ

```java
document.merge(filesForMerge, outStream);
```

หลังจากเรียกนี้, `mergedXPSfiles.xps` จะมีทุกหน้าจาก `input.xps`, `Demo.xps`, และ `sample.xps` ตามลำดับที่คุณกำหนด

## วิธีรวมไฟล์ XPS ใน Java คืออะไร?
เมธอด `append` ของ `XpsDocument` จะเพิ่มทุกหน้าจาก XpsDocument อื่นเข้าไปในเอกสารปัจจุบัน โหลดเอกสาร XPS ฐานด้วย `new XpsDocument("input.xps")`, จากนั้นเรียก `document.append(new XpsDocument("other.xps"))` สำหรับแต่ละไฟล์เพิ่มเติม, และสุดท้ายเรียก `document.save("merged.xps")`. เมธอด `append` จะเพิ่มหน้าของเอกสาร XPS ที่ระบุเข้าไปในเอกสารปัจจุบัน, คงรูปแบบ, ฟอนต์, และกราฟิกเวกเตอร์ไว้ สำหรับชุดข้อมูลขนาดใหญ่, ให้วนลูปผ่านไดเรกทอรีและใช้รูปแบบเดียวกัน

## ปัญหาทั่วไปและวิธีแก้ไข
| ปัญหา | สาเหตุ | วิธีแก้ |
|-------|--------|-----|
| **`FileNotFoundException`** | เส้นทาง `dataDir` ไม่ถูกต้อง | ตรวจสอบว่าโฟลเดอร์มีอยู่และใช้ backslash คู่ (`\\`) บน Windows. |
| **License not found** | กำลังทำงานโดยไม่มีไลเซนส์ที่ถูกต้อง | ใช้ไลเซนส์ชั่วคราวจาก Aspose หรือซื้อไลเซนส์เต็ม |
| **Merged file is empty** | สตรีมเอาต์พุตไม่ได้ flush/close | เรียก `outStream.close()` หลังจาก `document.merge(...)`. |
| **Mismatched page sizes** | ไฟล์ XPS ต้นทางมีขนาดหน้าต่างกัน | ใช้ `document.setPageSize(...)` ก่อนการรวมเพื่อบังคับขนาดเดียวกัน |
