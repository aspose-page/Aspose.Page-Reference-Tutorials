# Aspose.Page .NET Tutorial: แก้ไขเอกสาร XPS

## บทนำ

ใน **aspose page .net tutorial** นี้ คุณจะได้เรียนรู้วิธีแก้ไขเอกสาร XPS อย่างโปรแกรมมิ่งด้วย Aspose.Page for .NET ไม่ว่าคุณต้องการแทรกลายเซ็น, เพิ่มลายน้ำ, หรือเพียงแค่วางข้อความกำหนดเองบนหน้า เราจะเดินผ่านทุกบรรทัดของโค้ด, อธิบายว่าทำไมแต่ละขั้นตอนจึงสำคัญ, และแชร์เคล็ดลับปฏิบัติเพื่อหลีกเลี่ยงข้อผิดพลาดทั่วไป เมื่อเสร็จสิ้นคุณจะสามารถแก้ไขไฟล์ XPS ได้ในไม่กี่นาที ไม่ใช่หลายชั่วโมง

### คำตอบอย่างรวดเร็ว
- **บทเรียนนี้ครอบคลุมอะไร?** การเพิ่มข้อความลายเซ็น (“Confirmed”) ไปยังหน้าที่เลือกของไฟล์ XPS  
- **ต้องใช้ไลบรารีใด?** Aspose.Page for .NET (เวอร์ชันล่าสุด)  
- **ต้องมีลิขสิทธิ์หรือไม่?** ลิขสิทธิ์ชั่วคราวใช้ได้สำหรับการทดสอบ; ต้องมีลิขสิทธิ์เต็มสำหรับการใช้งานจริง  
- **รองรับเวอร์ชัน .NET ใดบ้าง?** .NET Framework 4.5+, .NET Core 3.1+, .NET 5/6+  
- **ใช้เวลานานเท่าไหร่ในการทำงาน?** ประมาณ 10 นาทีสำหรับการแทรกลายเซ็นพื้นฐาน

## การแก้ไขเอกสาร XPS คืออะไร

การแก้ไขเอกสาร XPS หมายถึงการเปลี่ยนแปลงเนื้อหาภาพแบบโปรแกรมมิ่ง—เช่น การแทรกข้อความ, รูปภาพ, หรือรูปทรงเวกเตอร์—โดยคงลักษณะการจัดหน้าแบบคงที่ของไฟล์ไว้ เนื่องจาก XPS มีพื้นฐานเป็น XML การเปลี่ยนแปลงจึงทำโดยตรงกับโครงสร้างหน้าของเอกสารโดยไม่ต้องแปลงไฟล์, ทำให้ควบคุมการจัดหน้า, การพิมพ์, และกราฟิกได้อย่างแม่นยำ

## ทำไมต้องใช้ Aspose.Page เพื่อแก้ไขเอกสาร XPS

Aspose.Page มี API .NET แท้ที่ทำงานข้ามแพลตฟอร์ม, ไม่ต้องพึ่งพาไลบรารีภายนอก, และให้ประสิทธิภาพสูงสำหรับเอกสารขนาดใหญ่ มันให้ผู้พัฒนาการเข้าถึงระดับล่างของหน้า, glyphs, brushes, และ transforms, ทำให้สามารถสร้างลายเซ็น, ลายน้ำ, และกราฟิกซับซ้อนได้ด้วยการควบคุมละเอียด

## ข้อกำหนดเบื้องต้น

ก่อนเริ่ม, โปรดตรวจสอบว่าคุณมีสิ่งต่อไปนี้:

- **Aspose.Page for .NET** – ติดตั้งแพคเกจ NuGet หรือดาวน์โหลดไลบรารีจากเอกสารอย่างเป็นทางการ **[here](https://reference.aspose.com/page/net/)**  
- **Input XPS file** – รับตัวอย่างเอกสาร XPS (เช่น `input1.xps`) จาก **[Aspose releases page](https://releases.aspose.com/page/net/)**  
- **Working directory** – สร้างโฟลเดอร์บนเครื่องของคุณเพื่อเก็บไฟล์อินพุตและเอาต์พุตและบันทึกพาธเต็ม; คุณจะกำหนดพาธนี้ให้กับตัวแปร `dir` ในโค้ด  
- **Development environment** – Visual Studio 2019/2022, .NET Framework 4.7.2 หรือใหม่กว่า, หรือโครงการ .NET Core/5/6 ใด ๆ  

ตอนนี้ทุกอย่างพร้อมแล้ว, มาดำดิ่งสู่โค้ดกันเถอะ

## วิธีนำเข้า namespace สำหรับ Aspose.Page?

เพื่อทำงานกับ Aspose.Page คุณต้องนำเข้า namespace ที่เกี่ยวข้องที่ส่วนหัวของไฟล์ C# ของคุณ ซึ่งจะทำให้คอมไพเลอร์เข้าถึงประเภทต่าง ๆ เช่น `XpsDocument`, `Glyphs`, และ `SolidColorBrush` คลาส `XpsDocument` แทนไฟล์ XPS และให้การเข้าถึงหน้าและทรัพยากรของมัน  

```csharp
using Aspose.Page;
using Aspose.Page.Xps;
using Aspose.Page.Xps.XpsModel;
using System.IO;
using System.Drawing;
```

คำสั่ง `using` ทำให้คุณเข้าถึง `XpsDocument`, `Glyphs` และคลาสสำคัญอื่น ๆ ได้โดยตรง  

```csharp
using Aspose.Page.XPS;
using Aspose.Page.XPS.XpsModel;
using System.Drawing;
using System.IO;
```

## วิธีเปิดสตรีมเอกสาร XPS?

เปิดไฟล์ XPS ต้นฉบับโดยใช้ `FileStream` แบบอ่าน‑อย่างเดียวและส่งให้กับคอนสตรัคเตอร์ของ `XpsDocument` ซึ่งจะโหลดไฟล์เข้าสู่วัตถุ `XpsDocument` ที่ทำหน้าที่เป็นจุดเริ่มต้นสำหรับการแก้ไขทั้งหมด อย่าลืมห่อสตรีมในบล็อก `using` เพื่อให้ระบบปล่อยไฟล์อัตโนมัติ  

```csharp
string inputPath = Path.Combine(dir, "input1.xps");
using (FileStream fs = new FileStream(inputPath, FileMode.Open, FileAccess.Read))
{
    XpsDocument document = new XpsDocument(fs);
    // All further operations use the 'document' variable.
}
```

**Definition anchor:** คลาส `XpsDocument` เป็นอ็อบเจ็กต์ระดับบนของ Aspose.Page ที่บรรจุไฟล์ XPS เดียว, เปิดเผยหน้า, ทรัพยากร, และเมตาดาต้าสำหรับการจัดการ  

```csharp
// ExStart:3
// The path to the documents directory.
string dir = "Your Document Directory";
// Open a stream of XPS file
using (FileStream xpsStream = File.Open(dir + "input1.xps", FileMode.Open, FileAccess.Read))
{
    // Create PS document from stream
    XpsDocument document = new XpsDocument(xpsStream, new XpsLoadOptions());
    // Continue to the next step...
}
// ExEnd:3
```

*Pro tip:* ห่อสตรีมในบล็อก `using` เพื่อให้แน่ใจว่าการจัดการไฟล์จะถูกปล่อยอัตโนมัติ

## วิธีสร้างข้อความลายเซ็นใน XPS?

สร้าง `SolidColorBrush` เพื่อกำหนดสีที่ใช้เติมข้อความลายเซ็น, จากนั้นเตรียมสตริงที่ต้องการแสดง `SolidColorBrush` ให้สีเดียวสม่ำเสมอสำหรับการวาดเช่นข้อความหรือรูปทรง ปรับสีของแปรงให้ตรงกับแบรนด์ของคุณก่อนเพิ่ม glyphs  

```csharp
SolidColorBrush brush = new SolidColorBrush(document, Color.BlueViolet);
string signature = "Confirmed";
```

**Definition anchor:** `SolidColorBrush` เป็นอ็อบเจ็กต์การวาดที่เติมรูปทรงหรือข้อความด้วยสีเดียวสม่ำเสมอ  

```csharp
// ExStart:4
// Create fill of the signature text
XpsSolidColorBrush textFill = document.CreateSolidColorBrush(Color.BlueViolet);
// Continue to the next step...
// ExEnd:4
```

คุณสามารถเปลี่ยน `Color.BlueViolet` เป็น `System.Drawing.Color` ใดก็ได้ที่ตรงกับแบรนด์ของคุณ  

## วิธีกำหนดหน้าและเพิ่ม glyphs ของลายเซ็น?

เลือกหน้าที่ต้องการด้วย `SelectActivePage` แล้วเรียก `AddGlyphs` เพื่อวางข้อความลายเซ็นที่พิกัดที่ต้องการ `AddGlyphs` จะใส่ลำดับอักขระลงในหน้าที่ทำงานโดยใช้ฟอนต์, ขนาด, สไตล์, และแปรงที่ระบุ ปรับค่า X และ Y ให้ตรงตำแหน่งที่ต้องการอย่างแม่นยำ  

```csharp
int[] pages = { 1, 2, 3 };
foreach (int pageNumber in pages)
{
    XpsPage page = document.Pages[pageNumber - 1];
    page.SelectActivePage();
    page.AddGlyphs(100, 200, signature, "Arial", 24, FontStyle.Regular, brush);
}
```

**Definition anchor:** `AddGlyphs` ใส่ลำดับอักขระ (glyphs) ลงในหน้าที่ทำงานโดยใช้ฟอนต์, ขนาด, สไตล์, และแปรงที่กำหนด  

*Why these coordinates?* ค่าพิกัด X และ Y วัดเป็นจุด (1/72 inch) ปรับค่าเหล่านี้เพื่อวางข้อความให้ตรงกับตำแหน่งที่ต้องการบนเลย์เอาต์ของหน้า  

```csharp
// ExStart:5
// Define pages where signature will be set
int[] pageNumbers = new int[] {1, 2, 3};

// For every defined page set signature "Confirmed" at coordinates x=650 and y=950
for (int i = 0; i < pageNumbers.Length; i++)
{
    // Define active page
    document.SelectActivePage(pageNumbers[i]);

    // Create glyphs object
    XpsGlyphs glyphs = document.AddGlyphs("Arial", 24, FontStyle.Bold, 650, 900, "Confirmed");

    // Define fill for glyphs
    glyphs.Fill = textFill;
}
// Continue to the next step...
// ExEnd:5
```

## วิธีบันทึกการเปลี่ยนแปลงในเอกสาร XPS?

หลังจากเพิ่ม glyphs ที่ต้องการทั้งหมดแล้ว เรียกเมธอด `Save` ของอินสแตนซ์ `XpsDocument` เพื่อเขียนเนื้อหาที่แก้ไขแล้วลงไฟล์ใหม่ ฟังก์ชัน `Save` จะทำการซีเรียลไลซ์ตัวแทนในหน่วยความจำของเอกสารกลับเป็นรูปแบบ XPS, รักษาการเปลี่ยนแปลงทั้งหมดเช่นข้อความหรือกราฟิกที่เพิ่มเข้ามา ให้ตั้งชื่อไฟล์เอาต์พุตที่แตกต่างเพื่อหลีกเลี่ยงการเขียนทับไฟล์ต้นฉบับ  

```csharp
string outputPath = Path.Combine(dir, "input1_out.xps");
using (FileStream outFs = new FileStream(outputPath, FileMode.Create, FileAccess.Write))
{
    document.Save(outFs);
}
```

ไฟล์ใหม่ `input1_out.xps` ตอนนี้มีลายเซ็น “Confirmed” อยู่บนหน้า 1‑3 แล้ว  

```csharp
// ExStart:6
// Save changed XPS document
document.Save(dir + "input1_out.xps");
// ExEnd:6
```

## ปัญหาทั่วไปและวิธีแก้

| ปัญหา | สาเหตุ | วิธีแก้ |
|-------|-------|----------|
| **Signature not visible** | พิกัดผิดหรือไม่ได้เลือกหน้า | ตรวจสอบให้แน่ใจว่าได้เรียก `SelectActivePage` สำหรับแต่ละหน้าและปรับค่า X/Y |
| **Exception on `AddGlyphs`** | ฟอนต์ไม่ได้ติดตั้งบนเซิร์ฟเวอร์ | ตรวจสอบให้ฟอนต์ที่ระบุ (เช่น Arial) มีอยู่, หรือฝังฟอนต์กำหนดเองโดยใช้ `document.AddFont` |
| **Output file is corrupted** | สตรีมไม่ถูกปิดอย่างถูกต้อง | ใช้คำสั่ง `using` สำหรับสตรีมทั้งหมดและเรียก `document.Dispose()` หากจำเป็น |
| **Performance slowdown on large files** | โหลดเอกสารทั้งหมดเข้าสู่หน่วยความจำ | ประมวลผลหน้าเป็นชุดหรือใช้ `XpsLoadOptions` พร้อมตัวเลือกสตรีมมิ่ง (หากมีในเวอร์ชันใหม่) |
