# การแปลง Postscript เป็น PDF ด้วย Aspose.Page สำหรับ .NET

## บทนำ

หากคุณต้องการ **postscript to pdf conversion** อย่างรวดเร็วและเชื่อถือได้ Aspose.Page สำหรับ .NET มี API แบบ clean, code‑first ที่ทำงานหนักให้คุณ ในบทเรียนนี้เราจะเดินผ่านตัวอย่างจริงที่แสดงอย่างชัดเจน **วิธีแปลง PostScript** ไฟล์, เพิ่มฟอนต์ที่กำหนดเอง, และบันทึกผลลัพธ์เป็นเอกสาร PDF ที่คุณสามารถแจกจ่ายหรือเก็บถาวรได้ คุณยังจะเห็นว่าทำไมนักพัฒนาจึงเลือก Aspose.Page สำหรับงานแบตช์, การจัดการฟอนต์ที่กำหนดเอง, และการเรนเดอร์คุณภาพสูง—ทั้งหมดนี้โดยอยู่ในระบบนิเวศของ .NET

## คำตอบอย่างรวดเร็ว
- **What library handles the conversion?** Aspose.Page for .NET – ไลบรารี .NET แท้ที่ไม่มีการพึ่งพา external dependencies.  
- **Can I add my own fonts?** ใช่ – ตั้งค่า option `AdditionalFontsFolders` ให้ชี้ไปที่ไดเรกทอรีฟอนต์ที่กำหนดเองของคุณ.  
- **Is batch conversion possible?** แน่นอน; เพียงแค่วนลูปผ่านคอลเลกชันของไฟล์ PostScript และใช้ตรรกะการแปลงเดียวกันซ้ำ.  
- **Do I need a license for production?** จำเป็นต้องมีไลเซนส์เชิงพาณิชย์สำหรับการใช้งานจริง; มีเวอร์ชันทดลองฟรีสำหรับการประเมิน.  
- **Which .NET versions are supported?** .NET Framework 4.5+, .NET Core 3.1+, .NET 5/6/7+.

คุณสมบัติ `AdditionalFontsFolders` ให้คุณระบุไดเรกทอรีเพิ่มเติมที่มีฟอนต์ที่กำหนดเองเพื่อใช้ระหว่างการเรนเดอร์.

## การแปลง PostScript เป็น PDF คืออะไร?

การแปลง PostScript เป็น PDF หมายถึงการนำภาษาการอธิบายหน้า (PostScript) มารันเดอร์เป็นรูปแบบ PDF ที่พกพาได้และได้รับการสนับสนุนอย่างกว้างขวาง สิ่งนี้มีประโยชน์เมื่อคุณได้รับไฟล์พิมพ์เก่า, ต้องการเก็บเอกสาร, หรืออยากแสดงในเบราว์เซอร์โดยไม่ต้องใช้ปลั๊กอินเพิ่มเติม.

## ทำไมต้องใช้ Aspose.Page สำหรับ .NET?

Aspose.Page สำหรับ .NET ให้โซลูชันที่จัดการเต็มรูปแบบที่แปลงไฟล์ PostScript เป็น PDF โดยไม่ต้องใช้เครื่องมือภายนอก มันให้การเรนเดอร์คุณภาพสูง, รองรับฟอนต์ที่กำหนดเอง, และทำงานบน .NET runtime ที่รองรับทุกเวอร์ชัน ทำให้การปรับใช้ง่ายและเชื่อถือได้ ไลบรารีนี้เป็น thread‑safe, จัดการข้อผิดพลาดอย่างราบรื่น, และสามารถขยายสำหรับการประมวลผลแบตช์ในสภาพแวดล้อมเซิร์ฟเวอร์  
- **Zero external dependencies** – ไลบรารีจัดส่งเป็นแพ็กเกจ NuGet เพียงหนึ่งเดียว ลดความซับซ้อนของการปรับใช้.  
- **Full control over fonts** – คุณสามารถจัดหาได้สูงสุด **10 custom font folders** ด้วยคุณสมบัติ `AdditionalFontsFolders` เพื่อให้ทุก glyph ปรากฏตามที่ต้องการ.  
- **Robust error handling** – API สามารถกดข้อผิดพลาดการเรนเดอร์เล็กน้อยได้ขณะยังสร้าง PDF ที่ใช้งานได้; นอกจากนี้ยังแสดงคอลเลกชันของข้อยกเว้นสูงสุด **500 exceptions** สำหรับการตรวจสอบหลังการแปลง.  
- **Scalable for batch processing** – เครื่องมือแปลงเป็น thread‑safe และสามารถจัดการ **hundreds of files concurrently** บนเซิร์ฟเวอร์ 8‑core ปกติ, ประมวลผลไฟล์ PostScript 200‑หน้าในเวลาน้อยกว่า 2 วินาที.

เมื่อคุณมีข้อกำหนดครบแล้ว, มาดำเนินการตามขั้นตอนเพื่อ **postscript to pdf conversion** ด้วย Aspose.Page สำหรับ .NET.

## นำเข้า Namespaces

คำสั่ง `using` ให้คุณเข้าถึงคลาสการแปลงหลัก วางบรรทัดต่อไปนี้ที่ส่วนบนของไฟล์ซอร์ส C# ของคุณ:

```csharp
using Aspose.Page.EPS;
using Aspose.Page.EPS.Device;
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
```

## ขั้นตอนที่ 1: เริ่มต้น Streams

เริ่มต้นด้วยการกำหนดค่า stream อินพุตและเอาต์พุตสำหรับไฟล์ PostScript และ PDF. แทนที่ `"Your Document Directory"` ด้วยโฟลเดอร์จริงที่มีไฟล์ `.ps` ของคุณ.

```csharp
// The path to the documents directory.
string dataDir = "Your Document Directory";
// Initialize PDF output stream
System.IO.FileStream pdfStream = new System.IO.FileStream(dataDir + "outputPDF_out.pdf", System.IO.FileMode.Create, System.IO.FileAccess.Write);
// Initialize PostScript input stream
System.IO.FileStream psStream = new System.IO.FileStream(dataDir + "input.ps", System.IO.FileMode.Open, System.IO.FileAccess.Read);
PsDocument document = new PsDocument(psStream);
```

## ขั้นตอนที่ 2: ตั้งค่า Conversion Options

เพื่อควบคุมกระบวนการแปลง, สร้างอ็อบเจ็กต์ `Options` และกำหนดค่าพารามิเตอร์ที่จำเป็น ในตัวอย่างนี้เราเปิดใช้งานการกดข้อผิดพลาดเพื่อให้การแปลงดำเนินต่อไปแม้ว่าต้นฉบับจะมีปัญหาไม่สำคัญ.

คลาส `Options` รวมการตั้งค่าการแปลง เช่น การจัดการข้อผิดพลาดและการกำหนดค่าโฟลเดอร์ฟอนต์.

```csharp
// If you want to convert Postscript file despite of minor errors set this flag
bool suppressErrors = true;
// Initialize options object with necessary parameters.
PdfSaveOptions options = new PdfSaveOptions(suppressErrors);
// If you want to add a special folder where fonts are stored. Default fonts folder in OS is always included.
options.AdditionalFontsFolders = new string[] { @"{FONT_FOLDER}" };
```

> **Pro tip:** ใช้คุณสมบัติ `AdditionalFontsFolders` ทุกครั้งที่คุณต้องการ **add custom fonts pdf** ไฟล์ที่ไม่ได้ติดตั้งบน OS โฮสต์.

## ขั้นตอนที่ 3: เริ่มต้น PDF Device

สร้าง PDF device ที่จะรับหน้าที่เรนเดอร์ คุณสามารถระบุขนาดหน้า, ความละเอียดภาพ, และคำแนะนำการเรนเดอร์อื่น ๆ ได้ตามต้องการ.

คลาส `PdfDevice` รับหน้าที่เรนเดอร์และเขียนลงใน stream ของ PDF.

```csharp
// Default page size is 595x842 and it is not mandatory to set it in PdfDevice
Aspose.Page.EPS.Device.PdfDevice device = new Aspose.Page.EPS.Device.PdfDevice(pdfStream);
// But if you need to specify size and image format use the following line
//Aspose.Page.EPS.Device.PdfDevice device = new Aspose.Page.EPS.Device.PdfDevice(pdfStream, new System.Drawing.Size(595, 842));
```

## ขั้นตอนที่ 4: บันทึกเอกสาร

เรียกใช้เมธอด `Save` บน device, ส่ง stream เอาต์พุตและ options ที่คุณกำหนดไว้ก่อนหน้านี้.

เมธอด `Save` บน device จะเขียนเนื้อหาที่เรนเดอร์ลงใน stream เอาต์พุตโดยใช้ options ที่ระบุ.

```csharp
try
{
    document.Save(device, options);
}
finally
{
    psStream.Close();
    pdfStream.Close();
}
```

## ขั้นตอนที่ 5: ตรวจสอบข้อผิดพลาด

หลังจากการแปลง, ทำการวนลูปผ่านข้อยกเว้นที่จับได้เพื่อเข้าใจว่าข้อผิดพลาดเล็กน้อยใดบ้างที่ถูกกด. ขั้นตอนนี้สำคัญสำหรับงานแบตช์ขนาดใหญ่ที่คุณต้องการการตรวจสอบหลังการทำงาน.

คอลเลกชัน `Exceptions` มีข้อผิดพลาดที่ไม่สำคัญใด ๆ ที่จับได้ระหว่างการแปลง.

```csharp
// Review errors
if (suppressErrors)
{
    foreach (Exception ex in options.Exceptions)
    {
        Console.WriteLine(ex.Message);
    }
}
```

### ข้อผิดพลาดทั่วไปและวิธีหลีกเลี่ยง

| ปัญหา | สาเหตุ | วิธีแก้ |
|-------|--------|---------|
| ฟอนต์ไม่แสดง | ฟอนต์ที่กำหนดเองไม่ได้อยู่ในโฟลเดอร์ฟอนต์ของ OS | เพิ่มเส้นทางโฟลเดอร์ไปยัง `options.AdditionalFontsFolders` |
| หน้าหาย | ไฟล์ PostScript อินพุตมีข้อผิดพลาด | ตั้งค่า `suppressErrors = true` เพื่อให้การแปลงดำเนินต่อและตรวจสอบ `options.Exceptions` |
| ไฟล์เอาต์พุตล็อก | Stream ไม่ได้ปิดอย่างถูกต้อง | ปิดทั้ง `psStream` และ `pdfStream` เสมอในบล็อก `finally` (ตามตัวอย่าง) |
