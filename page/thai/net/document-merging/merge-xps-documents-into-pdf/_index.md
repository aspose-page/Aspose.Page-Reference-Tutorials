# แปลง XPS เป็น PDF ด้วย Aspose.Page สำหรับ .NET

## บทนำ

หากคุณต้องการ **แปลง XPS เป็น PDF** อย่างรวดเร็วพร้อมคงความคมของกราฟิกเวกเตอร์และข้อความ Aspose.Page สำหรับ .NET มี API พร้อมใช้ที่จัดการงานหนักให้คุณ ในบทเรียนนี้เราจะพาคุณผ่านขั้นตอนทั้งหมด—ตั้งแต่การโหลดไฟล์ XPS ไปจนถึงการบันทึก PDF คุณภาพสูง—เพื่อให้คุณสามารถผสานการแปลงนี้เข้าไปในแอปพลิเคชัน .NET ใดก็ได้ด้วยความมั่นใจ.

## คำตอบเร็ว
- **ไลบรารีที่จัดการ XPS → PDF คืออะไร?** Aspose.Page for .NET.
- **ต้องใช้บรรทัดโค้ดกี่บรรทัด?** ประมาณห้าขั้นตอนเชิงตรรกะ (≈ 30 บรรทัดทั้งหมด).
- **สามารถบีบอัดภาพใน PDF ได้หรือไม่?** ได้, ใช้ `PdfSaveOptions.ImageCompression`.
- **ต้องมีใบอนุญาตสำหรับการใช้งานจริงหรือไม่?** จำเป็นต้องมีใบอนุญาตเชิงพาณิชย์; มีการทดลองใช้ชั่วคราวให้ใช้ได้.
- **เวอร์ชัน .NET ที่รองรับ?** .NET Framework 4.5+, .NET Core 3.1+, .NET 5/6/7.

## วิธีแปลง XPS เป็น PDF ด้วย Aspose.Page?

โหลดไฟล์ XPS ด้วย `new XpsDocument(inputStream)` และเรียก `PdfDevice.Render` พร้อมส่งออบเจ็กต์ `PdfSaveOptions` ที่กำหนดค่าไว้—กระบวนการเดียวนี้จะแปลงเอกสารและเขียน PDF ไปยังสตรีมผลลัพธ์ การทำงานทั้งหมดดำเนินในหน่วยความจำ ดังนั้นไม่มีไฟล์ชั่วคราวถูกสร้างขึ้น และคุณสามารถเปิดใช้งานการบีบอัดภาพเพื่อลดขนาดไฟล์สุดท้ายได้ตามต้องการ.

## Aspose.Page สำหรับ .NET คืออะไร?

Aspose.Page for .NET เป็นไลบรารีการประมวลผลเอกสารที่ช่วยให้สร้าง, แปลง, และเรนเดอร์ XPS, PDF, และรูปแบบหน้าอื่น ๆ ได้โดยไม่ต้องใช้ Microsoft Office มันให้ API สำหรับการสร้าง, แก้ไข, และแปลงเอกสารแบบหน้า, รองรับกราฟิกเวกเตอร์และแรสเตอร์, และทำงานบนหลายแพลตฟอร์ม มันเปิดเผย API ระดับต่ำที่ให้ผู้พัฒนาควบคุมการตั้งค่าเรนเดอร์ได้อย่างละเอียด.

## ทำไมต้องใช้ Aspose.Page เพื่อแปลง XPS เป็น PDF?

Aspose.Page รองรับ **รูปแบบผลลัพธ์กว่า 30** และสามารถประมวลผล **ไฟล์ XPS 500 หน้า** ในเวลาน้อยกว่า **2 วินาที** บนเซิร์ฟเวอร์ทั่วไป ทั้งนี้ยังคงรักษาข้อมูลเวกเตอร์ไว้ ไลบรารียังมี **การบีบอัดภาพ** ในตัว (ลดได้สูงสุด 80 %) และ **การบีบอัดข้อความ**, ช่วยให้คุณสร้าง PDF ที่มีน้ำหนักเบาโดยไม่เสียคุณภาพ.

## ข้อกำหนดเบื้องต้น

ก่อนเริ่มบทเรียน, ตรวจสอบให้แน่ใจว่าคุณมีข้อกำหนดต่อไปนี้พร้อมใช้งาน:

- Aspose.Page for .NET: ตรวจสอบว่าคุณได้ติดตั้งไลบรารี Aspose.Page แล้ว คุณสามารถดาวน์โหลดได้จาก [here](https://releases.aspose.com/page/net/).
- ไฟล์เอกสาร: เตรียมไฟล์ XPS (`input.xps`) ไว้ในไดเรกทอรีที่คุณกำหนด.

## นำเข้า Namespaces

Namespaces `Aspose.Page.Xps` และ `Aspose.Page.Pdf` มีคลาสที่จำเป็นสำหรับการโหลดไฟล์ XPS และบันทึก PDF.

```csharp
using Aspose.Page.XPS;
```

ขั้นตอนนี้ทำให้คุณเข้าถึงคลาสและเมธอดที่จำเป็นสำหรับการแปลงเอกสาร.

## ขั้นตอนที่ 1: เริ่มต้น Streams

สร้าง `FileStream` สำหรับไฟล์ XPS ต้นทางและอีก `FileStream` สำหรับ PDF ปลายทาง การใช้คำสั่ง `using` รับประกันว่าการปล่อยสตรีมจะทำอย่างถูกต้อง.

```csharp
// ExStart:3
// The path to the documents directory.
string dataDir = "Your Document Directory";
// Initialize PDF output stream
using (System.IO.Stream pdfStream = System.IO.File.Open(dataDir + "XPStoPDF_out.pdf", System.IO.FileMode.OpenOrCreate, System.IO.FileAccess.Write))
// Initialize XPS input stream
using (System.IO.Stream xpsStream = System.IO.File.Open(dataDir + "input.xps", System.IO.FileMode.Open))
{
    // ...
}
// ExEnd:3
```

ขั้นตอนนี้เกี่ยวกับการตั้งค่าสตรีมอินพุตและเอาต์พุตสำหรับไฟล์ XPS และ PDF ตรวจสอบให้แน่ใจว่าใช้เส้นทางและชื่อไฟล์ที่ถูกต้อง.

## ขั้นตอนที่ 2: โหลดเอกสาร XPS

`XpsDocument` เป็นคลาสที่โหลดและแสดงไฟล์ XPS ในหน่วยความจำ  
ที่นี่เราจะโหลดเอกสาร XPS เข้าไปในออบเจ็กต์ `XpsDocument` เพื่อเตรียมการประมวลผลต่อไป.

```csharp
// ExStart:4
// Load XPS document form the stream
XpsDocument document = new XpsDocument(xpsStream, new XpsLoadOptions());
// or load XPS document directly from file. No xpsStream is needed then.
// XpsDocument document = new XpsDocument(inputFileName, new XpsLoadOptions());
// ExEnd:4
```

## ขั้นตอนที่ 3: เริ่มต้น Save Options

`PdfSaveOptions` กำหนดวิธีการบันทึก PDF รวมถึงการบีบอัดและการตั้งค่าหน้า  
ปรับแต่งออบเจ็กต์ `PdfSaveOptions` ตามความต้องการของคุณโดยระบุพารามิเตอร์เช่น การบีบอัดภาพ, การบีบอัดข้อความ, และหมายเลขหน้า.

```csharp
// ExStart:5
// Initialize options object with necessary parameters.
PdfSaveOptions options = new PdfSaveOptions()
{
    JpegQualityLevel = 100,
    ImageCompression = PdfImageCompression.Jpeg,
    TextCompression = PdfTextCompression.Flate,
    PageNumbers = new int[] { 1, 2, 6 }
};
// ExEnd:5
```

## ขั้นตอนที่ 4: สร้าง Rendering Device

`PdfDevice` เป็นเอนจินการเรนเดอร์ที่แปลงหน้าของ XPS เป็นเนื้อหา PDF  
`PdfDevice` คือเครื่องมือที่รับผิดชอบการเรนเดอร์เอกสาร XPS ไปเป็นรูปแบบ PDF.

```csharp
// ExStart:6
// Create rendering device for PDF format
PdfDevice device = new PdfDevice(pdfStream);
// ExEnd:6
```

## ขั้นตอนที่ 5: บันทึกเอกสาร

เรียก `PdfDevice.Render` พร้อมกับเอกสาร XPS ที่โหลดและสตรีมเอาต์พุต เมธอดนี้จะเขียนไฟล์ PDF ที่สอดคล้องเต็มรูปแบบลงดิสก์.

```csharp
// ExStart:7
document.Save(device, options);
// ExEnd:7
```

สุดท้ายบันทึกเอกสารโดยใช้เรนเดอร์ดิไวซ์และตัวเลือกที่ระบุ.

## ข้อผิดพลาดทั่วไปและเคล็ดลับ

- **การเป็นเจ้าของสตรีม:** ควรห่อสตรีมด้วยบล็อก `using` เสมอเพื่อหลีกเลี่ยงการล็อกไฟล์.
- **ไฟล์ขนาดใหญ่:** สำหรับไฟล์ XPS ที่ใหญ่กว่า 200 MB, พิจารณาเพิ่มค่า `BufferSize` บน `FileStream` เพื่อปรับปรุงประสิทธิภาพ.
- **คุณภาพภาพ:** หากต้องการภาพแบบไม่มีการสูญเสีย, ตั้งค่า `ImageCompression` เป็น `PdfImageCompression.None` แทน JPEG.

## คำถามเพิ่มเติม

**Q: ฉันจะบีบอัดภาพ PDF ระหว่างการแปลงอย่างไร?**  
A: ตั้งค่า `PdfSaveOptions.ImageCompression = PdfImageCompression.Jpeg` และอาจปรับ `JpegQuality` เพื่อสมดุลขนาดและคุณภาพ.

**Q: วิธีที่ดีที่สุดในการสร้าง PDF จาก XPS ในกระบวนการแบบแบตช์คืออะไร?**

**Q: ไลบรารีนี้รองรับ PDF ที่มีการป้องกันด้วยรหัสผ่านหรือไม่?**  
A: ได้, คุณสามารถกำหนดรหัสผ่านผ่าน `PdfSaveOptions.Password` ก่อนบันทึก.

**Q: .NET runtime ใดที่รองรับอย่างเป็นทางการ?**  
A: .NET Framework 4.5+, .NET Core 3.1+, และ .NET 5/6/7 รองรับเต็มรูปแบบ.

**Q: ฉันจะตรวจสอบว่าการแปลงคงรักษากราฟิกเวกเตอร์ไว้หรือไม่?**
