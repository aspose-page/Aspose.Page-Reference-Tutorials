## Jak převést PNG na PostScript pomocí Aspose.Page

Převod souboru PNG na PostScript je tak jednoduchý jako načtení PNG, definování, kde se má objevit, a zavolání metody `addImage`. `addImage` vloží zadaný obrázek do výstupu PostScript na určené místo. Tento přístup vám také umožní **vkládat objekty obrázků**, **zpracovávat průhledné PNG soubory** a aplikovat transformace **škálování a otáčení obrázku**—vše v jediném volání API.

### Vkládání obrázku (jak vložit obrázek)

Když zavoláte `document.addImage(image, rect)`, Aspose.Page se postará o vložení rastrových dat do výstupu PostScript. Metoda funguje s PNG, JPEG, BMP a dalšími běžnými formáty.

### Zpracování průhledných PNG (zpracování průhledných PNG)

Průhledné PNG jsou automaticky zachovány. Stačí zajistit, aby cílový PostScript prohlížeč podporoval alfa kanály, a obrázek se vykreslí s průhledností zachovanou.

### Škálování a otáčení (škálování a otáčení obrázku)

Velikost a orientaci můžete řídit úpravou rozměrů obdélníku nebo aplikací transformační matice před voláním `addImage`. To vám umožní **škálovat a otáčet obrázek** bez externích nástrojů pro zpracování obrázků.

## Jak přidat obrázek – přehled krok za krokem

Tento přehled poskytuje jasný, lineární proces pro vložení obrázku do PostScript dokumentu pomocí Aspose.Page. Postupujte podle jednotlivých kroků v pořadí: vytvořte dokument, načtěte obrázek, nastavte jeho pozici, vložte jej a nakonec uložte výsledek. Třída `Document` představuje soubor PostScript v paměti. Třída `Image` zapouzdřuje rastrová data, jako je PNG nebo JPEG. Třída `Rectangle` určuje souřadnice X, Y a rozměry pro umístění obrázku.

1. **Vytvořte objekt `Document`**, který představuje soubor PostScript, který chcete upravit.  
2. **Instancujte objekt `Image`** ze souboru, streamu nebo pole bajtů.  
3. **Definujte obdélník umístění** (X, Y, šířka, výška), kde se obrázek objeví.  
4. **Zavolejte `document.addImage(image, rect)`** pro vložení grafiky.  
5. **Uložte aktualizovaný dokument** zpět na disk nebo do streamu.

### Definiční kotvy

Třída `Document` je nejvyšší objekt Aspose.Page, který představuje jediný PostScript dokument v paměti. Třída `Image` zapouzdřuje rastrová data (PNG, JPEG, BMP atd.) a poskytuje metadata jako šířka, výška a barevná hloubka. Metoda `addImage` vloží instanci `Image` do `Document` na souřadnice definované objektem `Rectangle`.

**Q: Mohu přidat více obrázků na stejnou stránku PostScript?**  
A: Ano. Opakovaně zavolejte metodu `addImage` s různými obdélníky umístění.

**Q: Podporuje Aspose.Page také vektorovou grafiku?**  
A: Rozhodně. Můžete vložit SVG, EPS nebo dokonce surové příkazy PostScript vedle rastrových obrázků.

**Q: Jaké verze Javy jsou kompatibilní?**  
A: Knihovna funguje s Java 8 a novějšími, včetně Java 11, 17 a dalších LTS verzí.

**Q: Existuje způsob, jak otočit obrázek při jeho přidávání?**  
A: Ano. `Matrix` definuje geometrické transformace jako rotaci a škálování grafiky. Použijte API transformace `Matrix` k nastavení rotace před voláním `addImage`.

**Q: Jak zpracovat průhledné PNG?**  
A: Průhledné PNG jsou automaticky zachovány; stačí zajistit, aby cílový PostScript prohlížeč podporoval alfa kanály.

**Q: Jak převod PNG na PostScript ovlivňuje velikost souboru?**
