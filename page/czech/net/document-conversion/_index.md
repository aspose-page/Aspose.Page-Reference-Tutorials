## Co je Aspose Page Conversion?
Aspose Page Conversion je funkce Aspose.Page, která převádí soubory PostScript a XPS do PDF dokumentů.  
Čte vektorové formáty jako PostScript (.ps) a XPS (.xps) a vykresluje je jako vysoce věrné PDF soubory kompletně v paměti, čímž odstraňuje potřebu mezisouborů nebo externích nástrojů. API zachovává písma, grafiku a rozvržení a zároveň umožňuje programově nastavit velikost stránky, kompresi a metadata.

## Proč používat Aspose.Page pro .NET?
Aspose.Page pro .NET nabízí čistě řízené API, které nevyžaduje žádné nativní závislosti, podporuje .NET Framework 4.5+, .NET Core 3.1+ a .NET 5/6+ a poskytuje přesnost převodu nad 99 % pro písma a grafiku. Zpracovává soubory až o několika stovkách stránek během méně než sekundy na soubor na typickém serverovém hardwaru.

## Kdy zvolit Aspose Page Conversion?
Zvolte Aspose Page Conversion, když potřebujete spolehlivou, vysokorychlostní transformaci PostScript nebo XPS aktiv do prohledávatelných PDF, zejména v dávkových pipelinech, webových službách nebo migračních projektech. Vyniká při zpracování ve velkém měřítku, archivaci řízené shodou a scénářích, kde jsou nástroje třetích stran jako Ghostscript zakázány.

## Často kladené otázky

**Q: Jak programově převést PostScript do PDF?**  
`PostScriptDocument` is a class that loads a PostScript file and enables conversion to other formats.  
A: Use the `PostScriptDocument` class from Aspose.Page, load the .ps file, and call the `Save` method with the PDF format.

**Q: Existuje limit velikosti XPS souborů, které mohu převést?**  
A: Neexistuje pevný limit, ale velmi velké XPS dokumenty mohou vyžadovat zvýšenou alokaci paměti nebo streamingový převod.

**Q: Mohu během převodu přizpůsobit metadata PDF?**  
`PdfDocument` is a class representing a PDF file, allowing access to its metadata and content.  
A: Ano – po převodu můžete upravit vlastnost `Info` objektu `PdfDocument` a nastavit název, autora a další metadata.

**Q: Potřebuji samostatnou licenci pro každý typ převodu?**  
A: Ne – jedna licence Aspose.Page pokrývá všechny podporované formáty, včetně PostScript a XPS.

**Q: Co když zdrojový soubor obsahuje nepodporovanou grafiku?**  
A: Aspose.Page vykreslí podporované prvky a přeskočí neznámé, přičemž zaznamená varování, která můžete zkontrolovat.
