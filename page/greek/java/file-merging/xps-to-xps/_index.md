## Εισαγωγή πακέτων
Η κλάση `XpsDocument` είναι το κύριο αντικείμενο του Aspose.Page που αντιπροσωπεύει ένα μοναδικό αρχείο XPS στη μνήμη. Εισάγετε τους απαιτούμενους χώρους ονομάτων για να εργαστείτε με αυτήν την κλάση και τα συναφή βοηθητικά εργαλεία.

```java
import java.io.FileOutputStream;

import com.aspose.xps.XpsDocument;
```

## Βήμα 1: ρυθμίστε το έργο σας
Δημιουργήστε ένα νέο έργο Java στο επιλεγμένο IDE και προσθέστε τα αρχεία JAR του Aspose.Page στη διαδρομή κατασκευής του έργου. Αυτό εξασφαλίζει ότι ο μεταγλωττιστής μπορεί να εντοπίσει την κλάση `XpsDocument`.

## Βήμα 2: αρχικοποιήστε τη ροή εξόδου xps
Ρυθμίστε τη ροή εξόδου για το συνδυασμένο αρχείο XPS. Καθορίστε τον φάκελο όπου θέλετε να αποθηκευτεί το συγχωνευμένο αρχείο.

```java
String dataDir = "Your Document Directory";
FileOutputStream outStream = new FileOutputStream(dataDir + "mergedXPSfiles.xps");
```

> **Συμβουλή:** Χρησιμοποιήστε απόλυτη διαδρομή κατά την ανάπτυξη για να αποφύγετε το `FileNotFoundException`, στη συνέχεια μεταβείτε σε σχετική διαδρομή για την παραγωγή.

## Βήμα 3: φορτώστε το πρώτο αρχείο XPS
Φορτώστε το πρώτο αρχείο XPS που θα χρησιμεύσει ως βάση για τη συνένωση.

```java
XpsDocument document = new XpsDocument(dataDir + "input.xps");
```

Οι ιδιότητες του πρώτου εγγράφου (όπως το μέγεθος και ο προσανατολισμός της σελίδας) γίνονται προεπιλογή για το τελικό συνδυασμένο αρχείο.

## Βήμα 4: δημιουργήστε έναν πίνακα αρχείων XPS
Ετοιμάστε έναν πίνακα αρχείων XPS που θέλετε να συνδυάσετε με το πρώτο.

```java
String[] filesForMerge = new String[] { dataDir + "Demo.xps", dataDir + "sample.xps" };
```

Μπορείτε να προσθέσετε όσες διαδρομές αρχείων χρειάζεστε· ο πίνακας μπορεί να δημιουργηθεί δυναμικά από λίστα φακέλου αν το προτιμάτε.

## Βήμα 5: συγχώνευση και αποθήκευση
Εκτελέστε τη διαδικασία συγχώνευσης και αποθηκεύστε το αποτέλεσμα στην καθορισμένη ροή εξόδου.

```java
document.merge(filesForMerge, outStream);
```

Μετά από αυτήν την κλήση, το `mergedXPSfiles.xps` θα περιέχει όλες τις σελίδες από τα `input.xps`, `Demo.xps` και `sample.xps` με τη σειρά που καθορίσατε.

## Πώς να συνδυάσετε αρχεία xps σε Java;
Φορτώστε το βασικό έγγραφο XPS με `new XpsDocument("input.xps")`, στη συνέχεια καλέστε `document.append(new XpsDocument("other.xps"))` για κάθε επιπλέον αρχείο και, τέλος, εκτελέστε `document.save("merged.xps")`. Η μέθοδος `append` προσθέτει τις σελίδες του καθορισμένου εγγράφου XPS στο τρέχον έγγραφο. Αυτή η απλή ακολουθία συγχωνεύει οποιονδήποτε αριθμό εγγράφων XPS διατηρώντας τη διάταξη, τις γραμματοσειρές και τα διανυσματικά γραφικά. Για μεγάλες παρτίδες, κάντε βρόχο σε έναν φάκελο και εφαρμόστε το ίδιο μοτίβο.

## Συνηθισμένα προβλήματα και λύσεις
| Πρόβλημα | Αιτία | Διόρθωση |
|----------|-------|----------|
| **`FileNotFoundException`** | Λανθασμένη διαδρομή `dataDir` | Επαληθεύστε ότι ο φάκελος υπάρχει και χρησιμοποιήστε διπλές ανάποδες κάθετες (`\\`) στα Windows. |
| **License not found** | Εκτέλεση χωρίς έγκυρη άδεια | Εφαρμόστε μια προσωρινή άδεια από την Aspose ή αγοράστε πλήρη άδεια. |
| **Merged file is empty** | Η ροή εξόδου δεν έχει αδειάσει/κλειστεί | Καλέστε `outStream.close()` μετά το `document.merge(...)`. |
| **Mismatched page sizes** | Τα πηγαία αρχεία XPS έχουν διαφορετικές διαστάσεις | Χρησιμοποιήστε `document.setPageSize(...)` πριν τη συγχώνευση για να επιβάλετε ένα ενιαίο μέγεθος. |
