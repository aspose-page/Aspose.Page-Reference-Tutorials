Είτε χρειάζεστε να συνδυάσετε πολλαπλές αναφορές, παρουσιάσεις ή αρχειοθετημένα έγγραφα σε ένα ενιαίο πακέτο XPS, τα παρακάτω βήματα θα σας καθοδηγήσουν σε μια καθαρή, έτοιμη για παραγωγή υλοποίηση που λειτουργεί σε οποιαδήποτε πλατφόρμα.

- **Ποιες εκδόσεις της Java υποστηρίζονται;** Java 8 και νεότερες (συνιστάται JDK 11+).

## Τι είναι η συγχώνευση αρχείων XPS;
Η συγχώνευση αρχείων XPS είναι η διαδικασία συνένωσης πολλαπλών εγγράφων XPS σε ένα ενιαίο συνεχόμενο αρχείο XPS, διατηρώντας τη διάταξη, τις γραμματοσειρές και τα γραφικά κάθε σελίδας. Δεν τροποποιεί το περιεχόμενο των μεμονωμένων σελίδων· απλώς τις ενώνει με τη σειρά που καθορίζετε, δημιουργώντας ένα ενοποιημένο έγγραφο που διατηρεί την οπτική πιστότητα των αρχικών.

## Εισαγωγή πακέτων
Η κλάση `XpsDocument` αντιπροσωπεύει ένα αρχείο XPS στη μνήμη και παρέχει μεθόδους για φόρτωση, επεξεργασία και αποθήκευση εγγράφων XPS.

```java
import java.io.FileOutputStream;

import com.aspose.xps.XpsDocument;
```

## Βήμα 1: ρυθμίστε το έργο σας
Δημιουργήστε ένα νέο έργο Java στο επιλεγμένο IDE και προσθέστε τα αρχεία JAR της Aspose.Page στη διαδρομή κατασκευής του έργου. Αυτό εξασφαλίζει ότι ο μεταγλωττιστής μπορεί να εντοπίσει την κλάση `XpsDocument`.

## Βήμα 2: αρχικοποιήστε τη ροή εξόδου xps
Ρυθμίστε τη ροή εξόδου για το συνδυασμένο αρχείο XPS. Καθορίστε τον φάκελο όπου θέλετε να αποθηκευτεί το συγχωνευμένο αρχείο.

```java
String dataDir = "Your Document Directory";
FileOutputStream outStream = new FileOutputStream(dataDir + "mergedXPSfiles.xps");
```

> **Συμβουλή:** Χρησιμοποιήστε απόλυτη διαδρομή κατά την ανάπτυξη για να αποφύγετε το `FileNotFoundException`, στη συνέχεια μεταβείτε σε σχετική διαδρομή για την παραγωγή.

## Βήμα 3: φορτώστε το πρώτο αρχείο XPS
Φορτώστε το πρώτο αρχείο XPS που θα λειτουργήσει ως βάση για τη συγχώνευση.

```java
XpsDocument document = new XpsDocument(dataDir + "input.xps");
```

Οι ιδιότητες του πρώτου εγγράφου (όπως το μέγεθος και ο προσανατολισμός της σελίδας) γίνονται προεπιλογή για το τελικό συνδυασμένο αρχείο.

## Βήμα 4: δημιουργήστε έναν πίνακα αρχείων XPS
Προετοιμάστε έναν πίνακα αρχείων XPS που θέλετε να συνδυάσετε με το πρώτο.

```java
String[] filesForMerge = new String[] { dataDir + "Demo.xps", dataDir + "sample.xps" };
```

Μπορείτε να προσθέσετε όσες διαδρομές αρχείων χρειάζεστε· ο πίνακας μπορεί να δημιουργηθεί δυναμικά από λίστα φακέλου εάν προτιμάτε.

## Βήμα 5: συγχωνεύστε και αποθηκεύστε
Εκτελέστε τη διαδικασία συγχώνευσης και αποθηκεύστε το αποτέλεσμα στην καθορισμένη ροή εξόδου.

```java
document.merge(filesForMerge, outStream);
```

Μετά από αυτήν την κλήση, το `mergedXPSfiles.xps` θα περιέχει όλες τις σελίδες από τα `input.xps`, `Demo.xps` και `sample.xps` με τη σειρά που καθορίσατε.

## Πώς να συγχωνεύσετε αρχεία XPS σε Java;
Η μέθοδος `append` της `XpsDocument` προσθέτει όλες τις σελίδες από ένα άλλο XpsDocument στο τρέχον έγγραφο. Φορτώστε το βασικό έγγραφο XPS με `new XpsDocument("input.xps")`, στη συνέχεια καλέστε `document.append(new XpsDocument("other.xps"))` για κάθε επιπλέον αρχείο και, τέλος, εκτελέστε `document.save("merged.xps")`. Η μέθοδος `append` προσθέτει τις σελίδες του καθορισμένου εγγράφου XPS στο τρέχον έγγραφο, διατηρώντας τη διάταξη, τις γραμματοσειρές και τα διανυσματικά γραφικά. Για μεγάλες παρτίδες, κάντε βρόχο σε έναν φάκελο και εφαρμόστε το ίδιο μοτίβο.

## Συνηθισμένα προβλήματα και λύσεις
| Issue | Reason | Fix |
|-------|--------|-----|
| **`FileNotFoundException`** | Λάθος διαδρομή `dataDir` | Επαληθεύστε ότι ο φάκελος υπάρχει και χρησιμοποιήστε διπλές ανάστροφες καθέτους (`\\`) στα Windows. |
| **License not found** | Εκτέλεση χωρίς έγκυρη άδεια | Εφαρμόστε μια προσωρινή άδεια από την Aspose ή αγοράστε πλήρη άδεια. |
| **Merged file is empty** | Η ροή εξόδου δεν έχει αδειάσει/κλειστεί | Καλέστε `outStream.close()` μετά το `document.merge(...)`. |
| **Mismatched page sizes** | Τα πηγαία αρχεία XPS έχουν διαφορετικές διαστάσεις | Χρησιμοποιήστε `document.setPageSize(...)` πριν τη συγχώνευση για να επιβάλετε ένα ενιαίο μέγεθος. |
