Η συγχώνευση XPS σε PDF συνδυάζει πολλαπλά αρχεία XPS (XML Paper Specification) σε ένα ενιαίο έγγραφο PDF διατηρώντας τα διανυσματικά γραφικά, τις ενσωματωμένες γραμματοσειρές και την ακριβή διάταξη των σελίδων. Αυτή η διαδικασία εξασφαλίζει ότι η οπτική πιστότητα των αρχικών εγγράφων διατηρείται, καθιστώντας το παραγόμενο PDF ιδανικό για αρχειοθέτηση, μαζική εκτύπωση ή κοινή χρήση χωρίς καμία απώλεια ποιότητας.

Το Aspose.Page for .NET σας επιτρέπει να μετατρέπετε και να συγχωνεύετε αρχεία XPS χωρίς εξωτερικά εργαλεία, παρέχοντας εξόδους PDF υψηλής ποιότητας σε μεγάλη κλίμακα. ## Πώς να μετατρέψετε XPS σε PDF χρησιμοποιώντας το Aspose.Page for .NET;

`Document` είναι η κλάση του Aspose.Page που αντιπροσωπεύει ένα έγγραφο και παρέχει μεθόδους για φόρτωση, επεξεργασία και αποθήκευση αρχείων XPS ή PDF.

Φορτώστε κάθε αρχείο XPS με την κλάση `Document`, προσθέστε τις σελίδες του σε ένα νέο έγγραφο PDF και αποθηκεύστε το αποτέλεσμα. Αυτή η προσέγγιση δύο βημάτων—δημιουργία ενός πηγαίου `Document` και κλήση του `Save` στο τελικό PDF—χειρίζεται αυτόματα γραμματοσειρές, εικόνες και διανυσματικά γραφικά, παραδίδοντας ένα αναζητήσιμο PDF σε δευτερόλεπτα.

### Προαπαιτούμενα
- .NET Framework 4.5+ ή .NET Core 3.1+ (συμπεριλαμβανομένων .NET 5/6/7)  
- Πακέτο NuGet Aspose.Page for .NET (`Aspose.Page`) εγκατεστημένο  
- Έγκυρη άδεια Aspose για παραγωγική χρήση (η δοκιμαστική λειτουργεί για δοκιμές)

### Διαδικασία βήμα‑βήμα
1. **Create a PDF container** – δημιουργήστε ένα νέο αντικείμενο `Document` που θα περιέχει το συγχωνευμένο αποτέλεσμα.  
2. **Load each XPS source** – χρησιμοποιήστε `new Document("source.xps")` για κάθε αρχείο XPS που χρειάζεται να συγχωνευθεί.  
3. **Append pages** – καλέστε `pdfDocument.Pages.AddRange(xpsDocument.Pages)` για να αντιγράψετε τις σελίδες στο PDF container.  
4. **Save the merged PDF** – εκτελέστε `pdfDocument.Save("merged.pdf", SaveFormat.Pdf)`· η βιβλιοθήκη ενσωματώνει αυτόματα τις γραμματοσειρές και διατηρεί τα διανυσματικά γραφικά.

> *Pro tip:* Για πολύ μεγάλες δέσμες, επεξεργαστείτε τα αρχεία σε ομάδες των 20–30 ώστε η χρήση μνήμης να παραμείνει χαμηλή, στη συνέχεια συγχωνεύστε τα ενδιάμεσα PDFs.
