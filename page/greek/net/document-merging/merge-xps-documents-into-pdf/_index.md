## Πώς να μετατρέψετε XPS σε PDF χρησιμοποιώντας το Aspose.Page;

Φορτώστε το αρχείο XPS με `new XpsDocument(inputStream)` και καλέστε `PdfDevice.Render` περνώντας μια ρυθμισμένη παρουσία `PdfSaveOptions` — αυτή η ενιαία διαδικασία μετατρέπει το έγγραφο και γράφει το PDF σε ένα ρεύμα εξόδου. Η ολόκληρη λειτουργία εκτελείται στη μνήμη, έτσι δεν δημιουργούνται προσωρινά αρχεία, και μπορείτε προαιρετικά να ενεργοποιήσετε τη συμπίεση εικόνας για να μειώσετε το τελικό μέγεθος του αρχείου.

## Εισαγωγή Χώρων Ονομάτων

Οι χώροι ονομάτων `Aspose.Page.Xps` και `Aspose.Page.Pdf` περιέχουν τις κλάσεις που απαιτούνται για τη φόρτωση αρχείων XPS και την αποθήκευση PDF.

```csharp
using Aspose.Page.XPS;
```

Αυτό το βήμα εξασφαλίζει ότι έχετε πρόσβαση στις κλάσεις και τις μεθόδους που απαιτούνται για τη μετατροπή του εγγράφου.

## Βήμα 1: Αρχικοποίηση Ροών

Δημιουργήστε ένα `FileStream` για το πηγαίο αρχείο XPS και ένα άλλο `FileStream` για το προορισμό PDF. Η χρήση δηλώσεων `using` εγγυάται ότι οι ροές θα απελευθερωθούν σωστά.

```csharp
// ExStart:3
// The path to the documents directory.
string dataDir = "Your Document Directory";
// Initialize PDF output stream
using (System.IO.Stream pdfStream = System.IO.File.Open(dataDir + "XPStoPDF_out.pdf", System.IO.FileMode.OpenOrCreate, System.IO.FileAccess.Write))
// Initialize XPS input stream
using (System.IO.Stream xpsStream = System.IO.File.Open(dataDir + "input.xps", System.IO.FileMode.Open))
{
    // ...
}
// ExEnd:3
```

Αυτό το βήμα περιλαμβάνει τη ρύθμιση των ροών εισόδου και εξόδου για τα αρχεία XPS και PDF. Βεβαιωθείτε ότι χρησιμοποιούνται οι σωστές διαδρομές και ονόματα αρχείων.

## Βήμα 2: Φόρτωση Εγγράφου XPS

`XpsDocument` είναι μια κλάση που φορτώνει και αντιπροσωπεύει ένα αρχείο XPS στη μνήμη.  
Εδώ, φορτώνουμε το έγγραφο XPS στο αντικείμενο `XpsDocument`, προετοιμάζοντάς το για περαιτέρω επεξεργασία.

```csharp
// ExStart:4
// Load XPS document form the stream
XpsDocument document = new XpsDocument(xpsStream, new XpsLoadOptions());
// or load XPS document directly from file. No xpsStream is needed then.
// XpsDocument document = new XpsDocument(inputFileName, new XpsLoadOptions());
// ExEnd:4
```

## Βήμα 3: Αρχικοποίηση Επιλογών Αποθήκευσης

`PdfSaveOptions` ρυθμίζει τον τρόπο αποθήκευσης του PDF, συμπεριλαμβανομένης της συμπίεσης και των ρυθμίσεων σελίδας.  
Προσαρμόστε το αντικείμενο `PdfSaveOptions` σύμφωνα με τις προτιμήσεις σας, καθορίζοντας παραμέτρους όπως η συμπίεση εικόνας, η συμπίεση κειμένου και οι αριθμοί σελίδων.

```csharp
// ExStart:5
// Initialize options object with necessary parameters.
PdfSaveOptions options = new PdfSaveOptions()
{
    JpegQualityLevel = 100,
    ImageCompression = PdfImageCompression.Jpeg,
    TextCompression = PdfTextCompression.Flate,
    PageNumbers = new int[] { 1, 2, 6 }
};
// ExEnd:5
```

## Βήμα 4: Δημιουργία Συσκευής Απόδοσης

`PdfDevice` είναι η μηχανή απόδοσης που μετατρέπει τις σελίδες XPS σε περιεχόμενο PDF.  
Το `PdfDevice` είναι το εργαλείο που είναι υπεύθυνο για την απόδοση του εγγράφου XPS σε μορφή PDF.

```csharp
// ExStart:6
// Create rendering device for PDF format
PdfDevice device = new PdfDevice(pdfStream);
// ExEnd:6
```

## Βήμα 5: Αποθήκευση Εγγράφου

Κληθείτε το `PdfDevice.Render` με το φορτωμένο έγγραφο XPS και τη ροή εξόδου. Η μέθοδος γράφει ένα πλήρως συμβατό αρχείο PDF στο δίσκο.

```csharp
// ExStart:7
document.Save(device, options);
// ExEnd:7
```

Τέλος, αποθηκεύστε το έγγραφο χρησιμοποιώντας τη συσκευή απόδοσης και τις καθορισμένες επιλογές.

## Συνηθισμένα Πιθανά Προβλήματα και Συμβουλές

- **Ιδιοκτησία ροής:** Πάντα τυλίγετε τις ροές σε μπλοκ `using` για να αποφύγετε κλειδώσεις αρχείων.
- **Μεγάλα αρχεία:** Για αρχεία XPS μεγαλύτερα από 200 MB, εξετάστε το ενδεχόμενο αύξησης του `BufferSize` στο `FileStream` για βελτίωση της απόδοσης.
- **Ποιότητα εικόνας:** Εάν χρειάζεστε εικόνες χωρίς απώλειες, ορίστε `ImageCompression` σε `PdfImageCompression.None` αντί για JPEG.
