# aspose.page create xps – Δημιουργία εγγράφου XPS με το Aspose.Page για .NET

## Εισαγωγή

Σε αυτό το σεμινάριο θα μάθετε πώς να δημιουργείτε έγγραφα **aspose.page create xps** βήμα‑βήμα χρησιμοποιώντας τη βιβλιοθήκη Aspose.Page για .NET. Είτε δημιουργείτε μια μηχανή αναφορών, έναν γεννήτρια τιμολογίων ή οποιοδήποτε σύστημα που χρειάζεται έγγραφα ηλεκτρονικά υψηλής πιστότητας, το XPS είναι μια αξιόπιστη, βασισμένη σε XML μορφή που διατηρεί τη διάταξη σε όλες τις πλατφόρμες. Θα καλύψουμε όλα, από τις προαπαιτήσεις μέχρι την αποθήκευση του τελικού αρχείου, με πρακτικές συμβουλές που μπορείτε να εφαρμόσετε αμέσως.

## Γρήγορες Απαντήσεις
- **Ποια βιβλιοθήκη χρειάζομαι;** Aspose.Page for .NET  
- **Μπορώ να το εκτελέσω σε .NET Core;** Ναι – πλήρως υποστηρίζεται σε .NET Core 3.1, .NET 5, .NET 6 και μεταγενέστερες εκδόσεις  
- **Πόσες γραμμές κώδικα;** Λιγότερες από 20 γραμμές για ένα βασικό αρχείο XPS “Hello World”  
- **Χρειάζομαι άδεια για δοκιμή;** Μια δωρεάν δοκιμή λειτουργεί για ανάπτυξη· απαιτείται άδεια για παραγωγικές εγκαταστάσεις  
- **Ποια μορφή έχει η έξοδος;** XPS (XML Paper Specification)  

## Πώς δημιουργώ ένα έγγραφο XPS με το Aspose.Page για .NET;

Φορτώστε τη βιβλιοθήκη Aspose.Page, δημιουργήστε ένα `XpsDocument`, προσθέστε μια σελίδα με γλύφους, ορίστε το χρώμα γεμίσματος και καλέστε `Save`. Αυτή η πλήρης ροή εργασίας απαιτεί μόνο λίγες κλήσεις μεθόδων και παράγει ένα αρχείο XPS σύμφωνο με τα πρότυπα, το οποίο μπορεί να ανοιχθεί σε Windows Reader, Adobe Acrobat ή οποιονδήποτε προβολέα XPS. Η προσέγγιση λειτουργεί σε Windows, Linux και macOS χωρίς πρόσθετες εξαρτήσεις.

## Τι είναι το aspose.page create xps;

`aspose.page create xps` αναφέρεται στη διαδικασία δημιουργίας ενός αρχείου XPS (XML Paper Specification) προγραμματιστικά χρησιμοποιώντας το API Aspose.Page για .NET. Το API αφαιρεί τις χαμηλού επιπέδου δομές PDF/XPS, επιτρέποντάς σας να εστιάσετε στο περιεχόμενο αντί στη λεπτομέρεια του μορφότυπου. Υποστηρίζει ορισμό μεγέθους σελίδας, γραμματοσειρών, χρωμάτων και ενσωμάτωση εικόνων, επιτρέποντας στους προγραμματιστές να δημιουργούν πλούσια, εκτυπώσιμα έγγραφα απευθείας από κώδικα.

## Γιατί να χρησιμοποιήσετε το Aspose.Page για δημιουργία XPS;

Aspose.Page υποστηρίζει **30+ μορφές εξόδου** και μπορεί να αποδώσει αρχεία XPS έως **500 MB** χωρίς να φορτώνει ολόκληρο το έγγραφο στη μνήμη, προσφέροντας υψηλή απόδοση σε εργασίες διακομιστή. Η βιβλιοθήκη εγγυάται τέλεια πιστότητα διάταξης pixel‑perfect, αυτόματη ενσωμάτωση γραμματοσειρών και πλήρη υποστήριξη Unicode, εξαλείφοντας την ανάγκη για τρίτους μετατροπείς.

## Εισαγωγή Ονομάτων Χώρων

Για να χρησιμοποιήσετε το Aspose.Page για .NET, πρέπει να εισάγετε τα απαραίτητα ονόματα χώρων στο έργο σας. Ακολουθήστε τα παρακάτω βήματα:

### Βήμα 1: Προσθήκη Αναφοράς στο Aspose.Page

Στο έργο σας, προσθέστε μια αναφορά στη βιβλιοθήκη Aspose.Page for .NET. Μπορείτε να βρείτε το απαιτούμενο DLL στο πακέτο που κατεβάσατε.

### Βήμα 2: Εισαγωγή Ονομάτων Χώρων

Συμπεριλάβετε τα παρακάτω ονόματα χώρων στο αρχείο κώδικα:

```csharp
using Aspose.Page.XPS;
using Aspose.Page.XPS.XpsModel;
using System.Drawing;
```

## Βήμα 1: Ορισμός Καταλόγου Εγγράφου

Η μεταβλητή `directoryPath` λέει στο API πού να γράψει το τελικό αρχείο XPS.

```csharp
string dir = "Your Document Directory";
```

Αντικαταστήστε το `"Your Document Directory"` με την πραγματική διαδρομή φακέλου στο σύστημά σας, π.χ., `C:\\Docs\\Output`.

## Βήμα 2: Δημιουργία Εγγράφου XPS

Η κλάση `XpsDocument` αντιπροσωπεύει το ριζικό αντικείμενο ενός αρχείου XPS.

```csharp
XpsDocument xDocs = new XpsDocument();
```

Αρχικοποιήστε την με το όνομα του αρχείου προορισμού και μια νέα σελίδα θα δημιουργηθεί αυτόματα.

## Βήμα 3: Προσθήκη Γλύφων στο Έγγραφο

Η μέθοδος `AddGlyphs` εισάγει κείμενο (γλύφους) στην τρέχουσα σελίδα.

```csharp
var glyphs = xDocs.AddGlyphs("Arial", 12, FontStyle.Regular, 300f, 450f, "Hello World!");
```

Μπορείτε να ελέγξετε την οικογένεια γραμματοσειράς, το μέγεθος, το στυλ και τις ακριβείς συντεταγμένες για ακριβή τοποθέτηση του κειμένου.

## Βήμα 4: Ορισμός Χρώματος Γέμισης Γλύφων

Η μέθοδος `SetFillColor` ορίζει το πινέλο που χρησιμοποιείται για το χρώμα των γλύφων.

```csharp
glyphs.Fill = xDocs.CreateSolidColorBrush(Color.Black);
```

Σε αυτό το παράδειγμα χρησιμοποιούμε το μαύρο (`Color.Black`), αλλά υποστηρίζεται οποιοδήποτε χρώμα ARGB.

## Βήμα 5: Αποθήκευση Αποτελέσματος

Καλώντας το `Save` γράφει το έγγραφο XPS στο δίσκο.

```csharp
xDocs.Save(dir + "output.xps");
```

Το αρχείο θα περιέχει το κείμενο “Hello World!” που προσθέσατε στα προηγούμενα βήματα.

## Κοινές Συμβουλές & Προβλήματα

- **Διαδρομή Καταλόγου** – Χρησιμοποιήστε `Path.Combine(dir, "output.xps")` για να αποφύγετε ελλείψεις διαχωριστών διαδρομής στα Windows, Linux ή macOS.  
- **Διαθεσιμότητα Γραμματοσειράς** – Η καθορισμένη γραμματοσειρά πρέπει να είναι εγκατεστημένη στο σύστημα υποδοχής· διαφορετικά το Aspose θα αντικαταστήσει με εφεδρική γραμματοσειρά, κάτι που μπορεί να επηρεάσει τη διάταξη.  
- **Πολλαπλές Σελίδες** – Για έξοδο πολλαπλών σελίδων, δημιουργήστε επιπλέον αντικείμενα `XpsPage`, προσθέστε περιεχόμενο σε κάθε μία και καλέστε το `Save` μία φορά.
