# Μετατροπή Postscript σε PDF με Aspose.Page για .NET

## Εισαγωγή

Αν χρειάζεστε **postscript to pdf conversion** γρήγορα και αξιόπιστα, το Aspose.Page για .NET προσφέρει ένα καθαρό, code‑first API που κάνει τη βαριά δουλειά για εσάς. Σε αυτό το tutorial θα περάσουμε από ένα πραγματικό παράδειγμα που δείχνει ακριβώς **πώς να μετατρέψετε PostScript** αρχεία, να προσθέσετε προσαρμοσμένες γραμματοσειρές και να αποθηκεύσετε το αποτέλεσμα ως έγγραφο PDF που μπορείτε να διανείμετε ή να αρχειοθετήσετε. Θα δείτε επίσης γιατί οι προγραμματιστές επιλέγουν το Aspose.Page για εργασίες batch, διαχείριση προσαρμοσμένων γραμματοσειρών και αποτύπωση υψηλής πιστότητας — ενώ παραμένουν εντός του οικοσυστήματος .NET.

## Γρήγορες Απαντήσεις
- **Ποια βιβλιοθήκη διαχειρίζεται τη μετατροπή;** Aspose.Page for .NET – a native .NET library with no external dependencies.  
- **Μπορώ να προσθέσω τις δικές μου γραμματοσειρές;** Yes – set the `AdditionalFontsFolders` option to point at your custom font directory.  
- **Είναι δυνατή η batch μετατροπή;** Absolutely; simply loop over a collection of PostScript files and reuse the same conversion logic.  
- **Χρειάζομαι άδεια για παραγωγή;** A commercial license is required for production; a free trial is available for evaluation.  
- **Ποιες εκδόσεις .NET υποστηρίζονται;** .NET Framework 4.5+, .NET Core 3.1+, .NET 5/6/7+.

Η ιδιότητα `AdditionalFontsFolders` σας επιτρέπει να καθορίσετε επιπλέον καταλόγους που περιέχουν προσαρμοσμένες γραμματοσειρές για χρήση κατά την απόδοση.

## Τι είναι η μετατροπή PostScript σε PDF;

Η μετατροπή PostScript σε PDF σημαίνει τη λήψη μιας γλώσσας περιγραφής σελίδας (PostScript) και την απόδοσή της σε μορφή PDF, φορητή και ευρέως υποστηριζόμενη. Αυτό είναι χρήσιμο όταν λαμβάνετε παλιά αρχεία εκτύπωσης, χρειάζεστε να αρχειοθετήσετε έγγραφα ή θέλετε να τα εμφανίσετε σε προγράμματα περιήγησης χωρίς πρόσθετα.

## Γιατί να χρησιμοποιήσετε το Aspose.Page για .NET;

Το Aspose.Page για .NET παρέχει μια πλήρως διαχειριζόμενη λύση που μετατρέπει αρχεία PostScript σε PDF χωρίς εξωτερικά εργαλεία. Παρέχει απόδοση υψηλής πιστότητας, υποστηρίζει προσαρμοσμένες γραμματοσειρές και λειτουργεί σε οποιοδήποτε υποστηριζόμενο .NET runtime, καθιστώντας την ανάπτυξη απλή και αξιόπιστη. Η βιβλιοθήκη είναι thread‑safe, διαχειρίζεται τα σφάλματα με χάρη και κλιμακώνεται για επεξεργασία batch σε περιβάλλοντα διακομιστών.
- **Zero external dependencies** – η βιβλιοθήκη διανέμεται ως ένα μόνο πακέτο NuGet, μειώνοντας την πολυπλοκότητα της ανάπτυξης.  
- **Full control over fonts** – μπορείτε να παρέχετε έως και **10 προσαρμοσμένους φακέλους γραμματοσειρών** χρησιμοποιώντας την ιδιότητα `AdditionalFontsFolders`, εξασφαλίζοντας ότι κάθε γλύφη εμφανίζεται ακριβώς όπως προορίζεται.

- **Scalable for batch processing** – η μηχανή μετατροπής είναι thread‑safe και μπορεί να διαχειριστεί **εκατοντάδες αρχεία ταυτόχρονα** σε έναν τυπικό διακομιστή 8‑πυρήνων, επεξεργαζόμενη ένα αρχείο PostScript 200 σελίδων σε λιγότερο από 2 δευτερόλεπτα.

## Εισαγωγή Namespaces

Οι οδηγίες `using` σας δίνουν πρόσβαση στις βασικές κλάσεις μετατροπής. Τοποθετήστε τις παρακάτω γραμμές στην αρχή του αρχείου πηγαίου κώδικα C#:

```csharp
using Aspose.Page.EPS;
using Aspose.Page.EPS.Device;
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
```

## Βήμα 1: Αρχικοποίηση Streams

Ξεκινήστε αρχικοποιώντας τα streams εισόδου και εξόδου για τα αρχεία PostScript και PDF. Αντικαταστήστε το `"Your Document Directory"` με τον πραγματικό φάκελο που περιέχει τα `.ps` αρχεία σας.

```csharp
// The path to the documents directory.
string dataDir = "Your Document Directory";
// Initialize PDF output stream
System.IO.FileStream pdfStream = new System.IO.FileStream(dataDir + "outputPDF_out.pdf", System.IO.FileMode.Create, System.IO.FileAccess.Write);
// Initialize PostScript input stream
System.IO.FileStream psStream = new System.IO.FileStream(dataDir + "input.ps", System.IO.FileMode.Open, System.IO.FileAccess.Read);
PsDocument document = new PsDocument(psStream);
```

## Βήμα 2: Ορισμός Επιλογών Μετατροπής

Για να ελέγξετε τη διαδικασία μετατροπής, δημιουργήστε ένα αντικείμενο `Options` και ρυθμίστε τις απαραίτητες παραμέτρους. Σε αυτό το παράδειγμα ενεργοποιούμε την καταστολή σφαλμάτων ώστε η μετατροπή να συνεχίζεται ακόμη και αν η πηγή περιέχει μη‑κριτικά ζητήματα.

Η κλάση `Options` περιλαμβάνει τις ρυθμίσεις μετατροπής όπως η διαχείριση σφαλμάτων και η διαμόρφωση φακέλων γραμματοσειρών.

```csharp
// If you want to convert Postscript file despite of minor errors set this flag
bool suppressErrors = true;
// Initialize options object with necessary parameters.
PdfSaveOptions options = new PdfSaveOptions(suppressErrors);
// If you want to add a special folder where fonts are stored. Default fonts folder in OS is always included.
options.AdditionalFontsFolders = new string[] { @"{FONT_FOLDER}" };
```

> **Pro tip:** Χρησιμοποιήστε την ιδιότητα `AdditionalFontsFolders` όποτε χρειάζεται να **προσθέσετε προσαρμοσμένες γραμματοσειρές pdf** αρχεία που δεν είναι εγκατεστημένα στο λειτουργικό σύστημα του υπολογιστή.

## Βήμα 3: Αρχικοποίηση Συσκευής PDF

Δημιουργήστε μια συσκευή PDF που θα λαμβάνει τις αποδοθείσες σελίδες. Μπορείτε προαιρετικά να καθορίσετε το μέγεθος σελίδας, την ανάλυση εικόνας και άλλες υποδείξεις απόδοσης.

Η κλάση `PdfDevice` λαμβάνει τις αποδοθείσες σελίδες και τις γράφει σε ένα stream PDF.

```csharp
// Default page size is 595x842 and it is not mandatory to set it in PdfDevice
Aspose.Page.EPS.Device.PdfDevice device = new Aspose.Page.EPS.Device.PdfDevice(pdfStream);
// But if you need to specify size and image format use the following line
//Aspose.Page.EPS.Device.PdfDevice device = new Aspose.Page.EPS.Device.PdfDevice(pdfStream, new System.Drawing.Size(595, 842));
```

## Βήμα 4: Αποθήκευση Εγγράφου

Κληθείτε τη μέθοδο `Save` στη συσκευή, περνώντας το stream εξόδου και τις επιλογές που διαμορφώσατε νωρίτερα.

Η μέθοδος `Save` στη συσκευή γράφει το αποδοθέν περιεχόμενο στο stream εξόδου χρησιμοποιώντας τις καθορισμένες επιλογές.

```csharp
try
{
    document.Save(device, options);
}
finally
{
    psStream.Close();
    pdfStream.Close();
}
```

## Βήμα 5: Ανασκόπηση Σφαλμάτων

Μετά τη μετατροπή, επαναλάβετε τις καταγεγραμμένες εξαιρέσεις για να κατανοήσετε ποια μικρά ζητήματα καταστέφτηκαν. Αυτό το βήμα είναι ουσιώδες για μεγάλης κλίμακας batch εργασίες όπου χρειάζεστε έλεγχο μετά την εκτέλεση.

Η συλλογή `Exceptions` περιέχει τυχόν μη‑κριτικά σφάλματα που καταγράφηκαν κατά τη μετατροπή.

```csharp
// Review errors
if (suppressErrors)
{
    foreach (Exception ex in options.Exceptions)
    {
        Console.WriteLine(ex.Message);
    }
}
```

### Συνηθισμένα Πιθανά Σφάλματα & Πώς να τα Αποφύγετε

| Πρόβλημα | Γιατί Συμβαίνει | Διόρθωση |
|----------|----------------|----------|
| Γραμματοσειρές δεν εμφανίζονται | Οι προσαρμοσμένες γραμματοσειρές δεν βρίσκονται στο φάκελο γραμματοσειρών του OS | Προσθέστε τη διαδρομή του φακέλου στο `options.AdditionalFontsFolders` |
| Λείπουν σελίδες | Το εισαγόμενο PostScript έχει σφάλματα | Ορίστε `suppressErrors = true` για να συνεχίσετε τη μετατροπή και να ελέγξετε το `options.Exceptions` |
| Το αρχείο εξόδου είναι κλειδωμένο | Το stream δεν κλείνει σωστά | Πάντα κλείστε και τα `psStream` και `pdfStream` σε ένα μπλοκ `finally` (όπως φαίνεται) |
