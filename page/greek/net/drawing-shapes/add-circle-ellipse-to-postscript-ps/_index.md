## Εισαγωγή Ονομάτων Χώρων

Οι οδηγίες `using` φέρνουν τις κλάσεις του Aspose.Page στο πεδίο ορατότητας ώστε να μπορείτε να εργάζεστε άμεσα με γραφικά, χρώματα και έγγραφα PS.

```csharp
using Aspose.Page.EPS;
using Aspose.Page.EPS.Device;
using System.Drawing;
using System.Drawing.Drawing2D;
using System.IO;
```

Τώρα, ας αναλύσουμε το παράδειγμα σε πολλαπλά βήματα για να σας καθοδηγήσουμε στη διαδικασία προσθήκης κύκλων έλλειψης σε ένα έγγραφο PostScript.

## Πώς ορίζω τον φάκελο του εγγράφου;

Για να ενημερώσετε το πρόγραμμα πού θα αποθηκεύσει το παραγόμενο αρχείο PS, πρέπει να καθορίσετε μια διαδρομή φακέλου στην οποία η εφαρμογή μπορεί να γράψει. Χρησιμοποιήστε μια μεταβλητή όπως `dataDir` και αναθέστε της μια πλήρη ή σχετική διαδρομή· αυτή η διαδρομή θα συνδυαστεί με το όνομα του αρχείου εξόδου αργότερα στον κώδικα.  
> **Συμβουλή:** Χρησιμοποιήστε `Path.Combine(Environment.CurrentDirectory, "output")` για να δημιουργήσετε μια διαδρομή δια-πλατφόρμα και να αποφύγετε σκληρά κωδικοποιημένους διαχωριστές.

```csharp
// ExStart:1
// The path to the documents directory.
string dataDir = "Your Document Directory";
```

## Πώς δημιουργώ το ρεύμα εξόδου για το έγγραφο PostScript;

Η δημιουργία ενός ρεύματος εξόδου ανοίγει έναν χειριστή αρχείου στον οποίο η μηχανή Aspose.Page θα γράψει τα δεδομένα PostScript. Με τη χρήση ενός `FileStream` με `FileMode.Create`, το αρχείο δημιουργείται φρέσκο σε κάθε εκτέλεση, αντικαθιστώντας τυχόν προηγούμενη έκδοση. Αυτό το ρεύμα περνάει στη συνέχεια στον κατασκευαστή `PsDocument`.

```csharp
//Create output stream for PostScript document
using (Stream outPsStream = new FileStream(dataDir + "AddEllipse_outPS.ps", FileMode.Create))
```

## Πώς ρυθμίζω τις επιλογές αποθήκευσης και αρχικοποιώ ένα έγγραφο PS;

`PsSaveOptions` σας επιτρέπει να ορίσετε μέγεθος σελίδας, ανάλυση και άλλες ρυθμίσεις απόδοσης. Εδώ χρησιμοποιούμε το τυπικό μέγεθος σελίδας A4 και ένα έγγραφο μίας σελίδας. `PsDocument` αντιπροσωπεύει το έγγραφο PostScript που δημιουργείται· λαμβάνει το ρεύμα εξόδου και τις επιλογές αποθήκευσης και διαχειρίζεται τα γεγονότα του κύκλου ζωής της σελίδας.

```csharp
//Create save options with A4 size
PsSaveOptions options = new PsSaveOptions();

// Create new 1-paged PS Document
PsDocument document = new PsDocument(outPsStream, options, false);
```

## Πώς δημιουργώ ένα graphics path για την πρώτη έλλειψη;

`GraphicsPath` αντιπροσωπεύει ένα διανυσματικό σχήμα που μπορεί να σχεδιαστεί ή να γεμίσει σε μια σελίδα PostScript. Ο κατασκευαστής δέχεται τις συντεταγμένες X/Y της επάνω‑αριστερής γωνίας, ακολουθούμενες από το πλάτος και το ύψος, επιτρέποντάς σας να ορίσετε το ακριβές μέγεθος και τη θέση της έλλειψης στη σελίδα.

```csharp
//Create graphics path from the first ellipse
System.Drawing.Drawing2D.GraphicsPath path = new System.Drawing.Drawing2D.GraphicsPath();
path.AddEllipse(new System.Drawing.RectangleF(250, 100, 150, 100));
```

## Πώς ορίζω το χρώμα και γεμίζω την πρώτη έλλειψη;

`SolidBrush` ορίζει ένα συμπαγές χρώμα γεμίσματος για τις λειτουργίες σχεδίασης. Δημιουργώντας ένα `SolidBrush` με ένα συγκεκριμένο `Color` και περνώντας το στη `graphics.FillPath`, η έλλειψη αποδίδεται με αυτό το συμπαγές χρώμα.

```csharp
//Set paint
document.SetPaint(new System.Drawing.SolidBrush(Color.Orange));
//Fill the ellipse
document.Fill(path);
```

## Πώς δημιουργώ ένα graphics path για τη δεύτερη έλλειψη;

Ένα δεύτερο `GraphicsPath` ορίζεται για να δείξει πώς μπορείτε να σχεδιάσετε ένα περίγραμμα (stroke) ξεχωριστά από το γέμισμα. Το ίδιο πρότυπο κατασκευής χρησιμοποιείται, αλλά μπορείτε να αλλάξετε τις διαστάσεις του ορθογωνίου για να παραγάγετε μια έλλειψη διαφορετικού μεγέθους.

```csharp
//Create graphics path from the second ellipse
path = new System.Drawing.Drawing2D.GraphicsPath();
path.AddEllipse(new System.Drawing.RectangleF(250, 300, 150, 100));
```

## Πώς ορίζω το στυλ περιγράμματος και σχεδιάζω τη δεύτερη έλλειψη;

`SolidPen` καθορίζει το χρώμα και το πάχος για το στυλ περιγράμματος. Παρέχοντας ένα `SolidPen` στη `graphics.DrawPath`, το περίγραμμα της έλλειψης σχεδιάζεται χωρίς κανένα γέμισμα, δίνοντάς σας ένα καθαρό σχήμα με περίγραμμα.

```csharp
//Set stroke
document.SetStroke(new System.Drawing.Pen(new System.Drawing.SolidBrush(Color.Red), 3));
//Stroke (outline) the ellipse
document.Draw(path);
```

## Πώς κλείνω την τρέχουσα σελίδα και αποθηκεύω το έγγραφο;

Αφού εκτελεστούν όλες οι εντολές σχεδίασης, πρέπει να κλείσετε τη ενεργή σελίδα με `document.ClosePage()` για να οριστικοποιήσετε το περιεχόμενό της. Τέλος, η κλήση `document.Save()` γράφει τα συγκεντρωμένα δεδομένα PostScript στο προηγουμένως ανοιγμένο ρεύμα, παράγοντας το αρχείο εξόδου στο δίσκο.

```csharp
//Close current page
document.ClosePage();

//Save the document
document.Save();
```
